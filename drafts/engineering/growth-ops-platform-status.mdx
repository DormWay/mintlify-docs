# Growth Ops Platform - Implementation Status

DormWay Growth Ops is a three-program platform providing student engagement opportunities:

## Platform Programs

### Labs
- Account-required FCFS (first-come, first-served) task pool model
- Live student dashboard and admin review flows

### Creators
- Public application flow with intent token, campus association, and optional video upload
- Admin review, pod management, account linking, and referral counter capabilities

### Ambassadors
- Account-based application flow with auto-approval
- Referral attribution sync with GetAmbassador
- Retention milestone tracking: onboarding + day-7 + week-4

## Live Platform Capabilities

- **Unified API**: Programs visibility via `GET /api/v2/students/me/programs`
- **Aligned surfaces**: Public and in-product programs surfaces use Labs/Creators/Ambassadors model
- **First-party Creator referrals**: Uses codes formatted as `cr_[a-f0-9]{8}` (not context IDs)
- **Ambassador referral mapping**: Preserves GetAmbassador integration with legacy-code compatibility
- **Milestone tracking**: Onboarding/day-7/week-4 tracking for both creators and ambassadors
