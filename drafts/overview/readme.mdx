# Growth Ops Platform

The Growth Ops Platform is a suite of tools in the dormway-admin dashboard for managing campus expansion, student recruitment, and growth initiatives.

**Location**: dormway-admin (Port 3004) → Growth section

## Features

### Campus Outreach CRM
**Status**: Production Ready

Manage campus expansion with:
- Campus list with smart filtering
- Contact management (student leaders, organizations)
- Activity tracking (events, campaigns, partnerships)
- AI-powered campus research (Perplexity Sonar)

### Bug Reports
**Status**: Production Ready

Student bug reporting system:
- Students can submit bugs with screenshots
- Admin dashboard for triaging and tracking
- Status tracking (submitted, in_progress, resolved, closed)
- Real-time updates via Ably
- Comments system with threading

### Labs Program
**Status**: Production Ready

Manage student workers ("Labs members"):
- Task assignment and tracking
- Payment workflow (assign → complete → verify → pay)
- Performance analytics with charts including:
  - Task metrics (completion rate, average payout)
  - Payment summary (total paid, pending)
  - Completion funnel visualization
  - Participant leaderboard
  - Trends over time
- Real-time updates via Ably

### Ambassador Program
**Status**: In Development

Campus ambassador recruitment and tracking:
- Referral tracking
- Conversion funnel
- Ambassador performance metrics

Current features:
- ✅ Referral list view (admin)
- ✅ Basic tracking
- 🚧 Ambassador detail view (planned)
- 🚧 Approval workflow (planned)
- 🚧 Performance analytics (planned)

## Technical Stack

### Backend
- **API Router**: Express.js endpoints in `services/api-router/src/routes/admin/`
- **Database**: PostgreSQL
- **AI**: Portkey + Perplexity Sonar for campus research

### Frontend
- **Framework**: React + Refine v4
- **UI Components**: MUI DataGrid
- **Build**: Vite
- **Auth**: Clerk (admin role required)

### External Services
- **Perplexity Sonar**: Web search LLM for campus research
- **Portkey**: AI gateway for observability
- **Helicone**: LLM cost tracking

## API Endpoints

### Campus Outreach
- `GET /admin/outreach/contacts` - List contacts
- `POST /admin/outreach/contacts` - Create contact
- `POST /admin/outreach/research/:campusId` - AI research
- `GET /admin/outreach/activities` - List activities
- `POST /admin/outreach/activities` - Create activity

### Bug Reports
- `POST /v2/students/me/bug-reports` - Submit bug (student)
- `GET /admin/bug-reports` - List bugs (admin)

### Labs Program
- `GET /admin/labs/tasks` - List tasks (admin)
- `GET /v2/students/me/labs/tasks` - My tasks (student)

### Ambassador Program
- `GET /admin/ambassadors` - List ambassadors (admin)
- `GET /v2/students/me/ambassador/stats` - My stats (student)

## Development

### Running Locally

```bash
# Start all services
make dev

# Access admin dashboard
open http://localhost:3004

# Login with admin account
# Navigate to Growth section
```

### Making Changes

```bash
# Frontend changes (dormway-admin)
cd services/dormway-admin
npm run dev  # Hot reload

# Backend changes (api-router)
cd services/api-router
# Make changes
docker restart docker-api-router-1  # Restart to apply
```

### Testing AI Research

```bash
# Via UI: Click magnifying glass icon in Campus List

# Via API:
curl -X POST http://localhost:3001/admin/outreach/research/{campusId} \
  -H "X-User-Id: 058d2a14-ab1a-49c0-aa67-0312fd87e342" \
  -H "X-User-Role: admin"
```
