## Production Guidelines

**Video Format:**
- Length: 30-55 seconds
- Platform: TikTok, Instagram Reels
- Style: Fast cuts, trending audio, bold text overlays
- Sound Effects: Notification sounds, "whoosh" transitions, "ding" confirmations

**Content Structure:**
- Hook (0-3s): Grab attention immediately
- Problem Setup (3-10s): Show current pain point
- Demo (10-40s): Show DormWay solution
- Payoff (40-47s): Results/benefits
- CTA (47-50s): "Link in bio" + app URL

**Target Metrics:**
- Views (48 hours): 50k+ for viral threshold
- Engagement Rate: 8%+
- Website Clicks: 2%+ conversion
- Expected total reach: 2M+ views across 20+ videos
