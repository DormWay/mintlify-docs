# Campus Priorities

DormWay's current campus strategy is deliberately narrow. The active operating plan says to focus on **5-8 target campuses**, build **10-15 Campus Leads** across that group, and avoid confusing broad awareness with local density.

<Note>
  The live operating focus is not the same thing as the older Top 50 expansion ranking. Current execution docs should win over older reference material when they disagree.
</Note>

---

## Current Execution Posture

These are the clearest campus-level truths in the current vault:

| Topic | Current truth |
|-------|---------------|
| **Overall scope** | Focus stays on 5-8 target campuses, not national spread. |
| **Beachhead experiments** | **UMich** and **UCLA** are the named beachheads in the April-August 2026 org plan. |
| **Campus Lead goal** | Build 10-15 Campus Leads across 5-8 campuses in May and June. |
| **Paid test campuses** | The latest paid-media reference dated April 14, 2026 names **UMich**, **UCLA**, and **South Carolina** in active geo-targeted Snapchat campaigns. |
| **August school type focus** | Residential semester schools first. Flexible-term expansion stays separate unless a pilot forces it. |
| **UCLA nuance** | UCLA ambassador contracts are treated as optional acceleration, not a dependency, in the current org plan. |

One important detail: the current source docs do **not** publish a final named list of all 5-8 active campuses beyond these explicit references. That is better represented as an in-progress operating set than as a frozen public roster.

---

## Why the Beachheads and the Top 50 List Do Not Match

There is a real mismatch in the vault, but it is explainable:

- The **current operating plan** chooses beachheads based on execution reality: founder access, existing density, current campus presence, and real activation potential.
- The **Top 50 expansion note** is a **draft** from **June 11, 2025** that ranks long-range expansion candidates by college-town characteristics and enrollment.

That is why **UMich** can be a current beachhead while sitting at **#19** in the older draft, and **UCLA** can be a current beachhead while sitting at **#49**. The two documents are solving different problems.

So the right way to read the campus strategy is:

1. Current execution: narrow, density-first, beachheads now.
2. Long-range sourcing reference: Top 50 list, useful for future expansion thinking.
