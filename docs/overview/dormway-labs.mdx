# DormWay Labs

DormWay Labs is the student task pool for improving the product directly. Students apply once, browse open work, claim tasks first-come-first-served, submit what they completed, and get paid on approved work.

It is intentionally lightweight: asynchronous, in-product, and designed to fit around the reality of a student's semester.

---

## How the Program Works

Labs currently runs on a **self-service first-come-first-served model**:

1. **Apply** from `/dashboard/programs`
2. **Get approved** by the team
3. **Browse the task pool** for open work, payouts, and deadlines
4. **Claim a task** before someone else does
5. **Submit the work** with notes, links, or both
6. **Get reviewed and paid** once the task is approved

---

## Task Types and Rewards

| Task Type | Description | Typical Payout |
|-----------|-------------|----------------|
| **Syllabus Upload** | Upload course syllabi from your campus | $2–5 per syllabus |
| **Bug Report** | Find and document bugs in the app | $5–20 based on severity |
| **QA Testing** | Test specific features and report issues | $5–15 per session |
| **Research** | User interviews, surveys, feedback | $10–25 per task |
| **Other** | Custom tasks as needed | Varies |

<Note>
  Reward amounts, task types, and review times can change as the program evolves. Use the task pool itself as the final source for current payout and deadline details.
</Note>

## Submitting Work

When a task is complete, the expected flow is:

1. Open the task
2. Submit a URL, notes, or both
3. Send it for review
4. Wait for approval, rejection, or requested fixes

### What good submissions usually include

- Following the task instructions exactly
- A readable deliverable, not a half-finished placeholder
- Enough context for the reviewer to understand what was done
- Bug reports with reproduction steps and proof
- Syllabus uploads that clearly show the schedule and grading rules

---

## Quality Guidelines

### Syllabus Uploads
- PDF is readable (not a blurry scan)
- Contains grading breakdown
- Contains course schedule
- Matches the course it is uploaded for
- Not a duplicate of an existing syllabus

### Bug Reports
- Clear, descriptive title
- Steps to reproduce
- Expected vs. actual behavior
- Screenshot or screen recording
- Platform info (iOS / web, browser, version)

## Deadlines and Task Management

- **Deadlines matter**: unsubmitted work can return to the pool
- **Unclaim if needed**: do it early so another student can take the task
- **Do not hoard tasks**: reliability matters more than claiming volume
- **Consistency counts**: repeated misses can affect future approval or access

---

## Payment Terms

- **Contractor status** — All Labs rewards are paid as 1099 independent contractor income
- **Tax responsibility** — Participants are responsible for applicable taxes on earnings
- **Weekly payouts** — Approved tasks are batched and paid weekly (typically Fridays)
- **Payout method** — Direct deposit or PayPal (configured during onboarding)
- **Confidentiality** — Participants agree to confidentiality regarding non-public product information
- **Terms subject to change** — DormWay reserves the right to modify reward amounts and program terms

## Application Process

1. Sign up for DormWay (if not already a user)
2. Navigate to **Programs** (`/dashboard/programs`)
3. Click **Apply** on the Labs card
4. Fill out the application:
   - why you want to join
   - your campus
   - any other requested background for the current application
5. Wait for approval (24–48 hours)
6. Start claiming tasks

Approval is meant to be lightweight. The main question is whether the student seems likely to complete work responsibly.

## Labs and Other Programs

DormWay also offers Ambassador and Creators programs. They are independent but complementary:

| Labs | Ambassador | Creators |
|------|------------|----------|
| Task-based work | Referral-based earnings | Content + referral earnings |
| In-product tasks | Campus outreach | Social/video-driven campus growth |
| Earn per task completed | Earn per successful referral | Earn via creator payout model |

Students can participate in more than one program at the same time if they are a good fit.

## API Reference

For technical reference, the current surface includes endpoints like:

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/v2/students/me/programs` | GET | Check Labs, Ambassador, and Creators status |
| `/v2/students/me/programs/labs/apply` | POST | Apply to Labs |
| `/admin/labs/pool` | GET | Get available tasks |
| `/admin/labs/tasks/:id/claim` | POST | Claim a task |
| `/admin/labs/tasks/:id/unclaim` | POST | Unclaim a task |
| `/admin/labs/tasks/:id` | PATCH | Submit completed task |
