# Product Capabilities

DormWay is a student OS — a platform that unifies every dimension of a student's academic life. This page catalogs every major capability and what it does.

---

## Canvas LMS Integration

DormWay connects directly to Canvas LMS via API token or ICS calendar feed. Once connected:

- **Course sync** — All enrolled courses appear in DormWay automatically
- **Assignment sync** — All Canvas assignments, due dates, submission types, and rubrics are available in real time
- **Grade tracking** — Grade postings from Canvas trigger instant push notifications; grades update in Tasks and Courses pages live
- **Announcement monitoring** — Course announcements surface in DormWay's notification feed
- **Real-time updates** — Changes in Canvas propagate to DormWay via Ably within seconds, not polling cycles

Canvas is the primary upstream data source for academic obligations. All Canvas data is read-only — DormWay does not write back to Canvas.

---

## Schedule Management

Students maintain a complete academic schedule inside DormWay:

- **Schedule import** — Upload a PDF or screenshot of your class schedule; AI extracts course names, times, days, rooms, and professors
- **Manual events** — Create study sessions, office hours appointments, meetings, and personal events
- **Google Calendar sync** — Two-way sync with Google Calendar; DormWay events appear in Google and vice versa
- **Recurring patterns** — Classes repeat on their weekly pattern; custom recurrence rules for other events
- **Time block management** — Create dedicated focus blocks scheduled around existing commitments
- **Visual calendar** — Day, week, and semester views with course color coding

## Syllabus Intelligence

When students upload a course syllabus (PDF), DormWay's AI crew analyzes it and produces a structured intelligence report. The report covers:

| Section | What It Provides |
|---------|-----------------|
| **Academic Pulse** | Real-time workload overview for the course |
| **Semester Heatmap** | Visual workload distribution by week |
| **Peak Weeks** | Identifies the highest-stress periods in the semester |
| **Conflict Analysis** | Detects overlapping deadlines across all courses |
| **Professor Insights** | Teaching style, grading patterns, office hours |
| **Key Policies** | Attendance rules, late work policy, grading breakdown |
| **Gotchas** | Important rules and edge cases to watch out for |
| **Contingency Plans** | Academic recovery scenarios if a student falls behind |
| **Success Framework** | Strategies for succeeding in that specific course |
| **Resource Requirements** | Required materials, software, textbooks |
| **Prerequisite Reality Check** | Validates readiness for the course |

**Special views:** Date Pivot (see all courses' events on a specific date), Swimlane Timeline (visual course progression), Weekly Workload Chart, and Collision Report (all deadline conflicts visualized).

## AI Day Plans

DormWay generates a personalized day plan for each student every morning at 05:00 campus local time (via the StudentWatcher Temporal workflow). The day plan:

- Incorporates the student's confirmed class schedule
- Pulls in upcoming Canvas assignments by due date and estimated effort
- Accounts for the student's location (campus, timezone, weather context)
- Surfaces in the **Today** widget on the dashboard

Day plans are the output of a multi-step workflow: the StudentWatcher digital twin monitors each student's context and triggers plan generation as part of the daily cycle.

## Crews — Group Coordination

Crews is DormWay's group collaboration workspace. Students create a Crew, choose a type, invite members, and get a purpose-built workspace:

**Crew types:**

| Type | Purpose |
|------|---------|
| Dorm | Floor or suite coordination — quiet hours, amenities, building issues |
| Study | Collaborative studying — find meeting times, share notes, track progress |
| Project | Coursework teams — task assignment, deadline sync, file sharing |
| Event | Planning gatherings — polls, RSVPs, event details |
| Coordination | General organizing — shared to-do lists, task claiming |
| Custom | Student-defined purpose |

**Core modules (active per crew type):**

- **Real-time chat** — Persistent history, emoji reactions, typing indicators
- **Find Times** — Members submit availability; system ranks top meeting slots by scoring "best," "okay," and "avoid" preferences
- **Deadline Sync** — For course-linked crews, Canvas assignment deadlines auto-populate into the shared task list
- **Polls** — Single or multi-select; anonymous or attributed voting
- **Shared Notes** — Course notes shared with the crew, organized by date
- **File Sharing + AI Q&A** — Upload documents; members can ask natural-language questions and get streamed answers sourced from their own files (via Ragie RAG)
- **Task Management** — Shared to-do lists with claiming, progress tracking, and completion
- **Quiet Hours** — Dorm crews can toggle exam mode and set scheduled quiet hours (visible to all floor members)

**Guest access:** Anyone can join a Crew via share link without a DormWay account. Guest members participate fully in one crew. When ready, they convert to a full account and keep all their data.

## Course Intelligence

Beyond individual tasks, DormWay surfaces per-course and cross-course intelligence:

- **Term Insights tab** — Semester workload analysis, conflict detection, peak weeks visualization, course correlation insights, academic success recommendations
- **Grade tracking** — Real-time grade updates from Canvas with notification on posting
- **Course overview** — Professor, credits, location, color coding, per-course documents

## Notes and Library

- **Notes Hub** (`/dashboard/notes-hub`) — MDX note editor with rich formatting (bold, italic, lists, code). Tag notes by course. Link notes to assignments. Search across all notes.
- **Library** (`/dashboard/library`) — Repository of recent lectures, recordings, and course materials. Quick access to frequently used resources.
- **iPad Lecture Notes** — Full PencilKit canvas with Apple Pencil support, audio recording with speech-to-text, synced playback, pin navigation.

## Personalization

- **Themes** — Six visual themes: Light, Dark, Glass (glassmorphic), Paper (minimal), Calm (muted), System (follows OS)
- **Font size** — Small, medium, large
- **Accent color** — Choose from color presets
- **Widget layout** — Drag to rearrange, resize, add, or remove dashboard widgets

## DormWay Labs

Labs is a student task-pool program where enrolled students earn money by helping improve DormWay — uploading syllabi, finding bugs, completing QA tasks, and doing user research. Managed at `/dashboard/labs`.

See [DormWay Labs](/docs/overview/dormway-labs) for full details.
