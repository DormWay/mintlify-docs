# How DormWay Works

DormWay is an intelligent academic management platform for college students. It combines your class schedule, assignments, course materials, and AI-powered tools into one unified system — available on web (app.dormway.com), iPhone, iPad, and Mac.

The platform's core value: give students smart context about what matters right now, so they can stay organized without chaos.

---

## Getting Started

### Step 1 — Create Your Account

Sign up at [app.dormway.com](https://app.dormway.com) with your school email, or download the iOS app from the App Store. Complete your student profile with name, campus, and major.

Authentication is handled by Clerk. Single sign-in works across web and iOS — no separate password needed per platform.

### Step 2 — Connect Canvas LMS

Go to **Settings → Connections → Canvas** and connect in one of two ways:

**API Key (recommended)**
1. In Canvas, go to Account → Settings → Approved Integrations
2. Create a new access token named "DormWay"
3. Paste the token into DormWay's Connections settings

**ICS Calendar Feed**
1. In Canvas, go to Calendar → Calendar Feed
2. Copy the ICS feed URL and paste it into DormWay

Once connected, DormWay syncs all enrolled courses, assignments with due dates, grade postings, and course announcements in real time via Ably pub/sub.

### Step 3 — Import Your Class Schedule

Go to **Schedule** and click **Import Schedule**. Upload a PDF or screenshot of your class schedule. DormWay's AI extracts:
- Course names and codes
- Class times and days
- Room locations and buildings
- Professor names

Review the extracted schedule, make any corrections, and confirm. Your schedule then populates across all platforms and drives time-awareness throughout the app.

### Step 4 — Upload Course Syllabi

Go to **Settings → Connections → Syllabus Manager** and upload PDFs for each course. DormWay's AI crew processes each syllabus and extracts:
- All assignment deadlines and exam dates
- Grading breakdown and policies
- Professor insights (teaching style, office hours, grading patterns)
- Peak workload weeks across the semester
- Conflict analysis — overlapping deadlines across courses

This analysis populates the **Term Insights** tab and per-course **Syllabus Intelligence** pages.

## Daily Use

### The Dashboard

Your main dashboard is a collection of customizable widgets. Each widget focuses on one slice of your academic life:

| Widget | What It Shows |
|--------|--------------|
| **Today** | Current day overview, weather, what's coming next |
| **Schedule** | Daily timeline with classes and events |
| **Tasks** | Upcoming assignments and to-dos |
| **Courses** | Enrolled courses from Canvas |
| **Heads Up** | AI-powered priority alerts |
| **Library** | Recent lectures, recordings, and notes |

Widgets can be resized, rearranged, or hidden. **Focus Mode** expands a single widget full-screen.

### Managing Assignments

When Canvas posts a new assignment, DormWay receives it in real time and surfaces it in the **Tasks** page. Three core actions:

1. **Plan** — Open the inline planner: a week-view calendar showing your existing schedule. Drag a time block to the day you want to work on it.
2. **Start** — Creates a 60-minute focus block in your schedule and focuses the task front-and-center.
3. **Complete** — Mark it done. Grade updates automatically when Canvas posts it.

The **Capacity Bar** shows your weekly required hours versus scheduled hours — a live sanity check against overcommitting.

### Task Organization

Tasks are grouped by urgency:
- **Overdue** — Past-due items needing immediate attention
- **Due Soon** — Upcoming deadlines
- **Later / Backlog** — Future tasks with no immediate pressure

Tasks come from multiple sources: Canvas sync (automatic), syllabus extraction (AI-derived from uploaded syllabi), and manual creation.

### Ace AI Assistant

Ace is DormWay's AI assistant, accessible from any page via the floating Ace button or at `/dashboard/ace`. Three modes:

- **Ace Chat** — Conversational Q&A with full course awareness. Ace knows your courses, syllabus data, and upcoming deadlines.
- **Ace Write** — Essay and paper drafting assistance. Grammar, citations, document editing.
- **Ace Documents** — AI-powered document analysis. Auto-generates notes and summaries from lectures and readings.

### Crews — Group Coordination

Crews is DormWay's shared workspace for groups: study groups, dorm floors, project teams, event committees. Each crew type activates only the modules relevant to it — a project crew gets deadline sync and file sharing; a dorm crew gets quiet hours. Built-in capabilities include real-time chat, smart scheduling (Find Times), polls, shared notes, and AI-powered document Q&A.

## Platform Coverage

| Platform | Experience |
|----------|-----------|
| **Web (app.dormway.com)** | Full-featured dashboard with all widgets, customizable layout |
| **iPhone** | Native iOS app with three-tab dashboard, home screen widgets, Live Activities |
| **iPad** | Native iOS app with full PencilKit lecture notes and audio recording |
| **Mac** | Mac Catalyst (same codebase as iOS), keyboard navigation, multi-window |

### iOS-Specific Features

- **Home Screen Widgets** — Small, medium, and large sizes showing next class, upcoming tasks, or full-day overview
- **Live Activities** — Class countdown in the Dynamic Island (iPhone 14 Pro and later)
- **Class Alarms** — Smart alarms via AlarmKit that break through Do Not Disturb and silent mode
- **Control Center Shortcuts** — Instant access to schedule, tasks, or Ace without opening the app
- **Siri Shortcuts** — "Hey Siri, what's my next class?" and similar voice queries

### iPad Lecture Notes

On iPad with Apple Pencil:
- Full PencilKit drawing canvas with pressure sensitivity
- Markdown text editor alongside drawings
- Audio recording with speech-to-text transcription, synced to note strokes
- Pin navigation for marking important moments in a recording

## Real-Time Architecture

DormWay uses Ably pub/sub to push live updates to all clients without polling:

- Canvas grade postings fire instantly when published
- New assignments surface in Tasks the moment Canvas posts them
- Schedule changes propagate immediately across web and iOS
- Context transitions (current class, next event) update in real time

ETag-based caching ensures unchanged data is not re-downloaded on every view, keeping the app fast even on slow connections.

## Common Workflows

### Morning Routine
1. Check the **Today** widget for a daily overview
2. Review **Heads Up** for AI-surfaced priority alerts
3. See **Schedule** for today's classes
4. Check **Tasks** for what's due soon

### Preparing for Exams
1. Open a course page → **Syllabus Insights → Exam Policies**
2. Review **Peak Weeks** to allocate study time
3. Use **Ace Chat** for concept review
4. Schedule focus sessions in the **Schedule** page

### Semester Planning
1. Upload all syllabi from **Settings → Connections → Syllabus Manager**
2. Go to **Courses → Term Insights** tab
3. Review the **Semester Heatmap** for workload distribution
4. Identify **Peak Weeks** and **Conflict Analysis** for overlapping deadlines
5. Block extra study time before crunch periods
