# DormWay

DormWay is a student OS — an AI-powered platform that helps college students manage their academic lives in one place. It integrates with Canvas LMS, parses syllabi, generates intelligent day plans, coordinates group collaboration, and provides an AI assistant named Ace.

Students use DormWay on the web at [app.dormway.com](https://app.dormway.com) and on iPhone and iPad via the native iOS app.
