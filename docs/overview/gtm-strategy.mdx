# GTM Strategy

DormWay's current GTM strategy is not a broad awareness launch. It is a density-first operating system built around a small campus set, a narrow scoreboard, and a hard rule that trust and instrumentation come before scale.

<Note>
  Active execution is intentionally narrow. The current operating contract says the live thread is the GTM Playbook, 4-Week Calendar, Copy Bank, Instrumentation Backlog, and Agentic Addendum. Other GTM docs are reference unless explicitly promoted.
</Note>

---

## Current Scoreboard

These are the metrics the current GTM docs treat as canonical:

| Metric | Why it matters |
|--------|----------------|
| **WFAU** | Tracks whether new users actually reach a first meaningful action inside seven days. |
| **Activation rate** | Shows how much of acquisition turns into real setup rather than empty signups. |
| **Time-to-first-value** | Keeps the team focused on how fast DormWay proves usefulness. |
| **D7 / D14 / W4 retention** | Measures whether setup becomes a habit instead of a one-time spike. |
| **Campus density** | Prevents DormWay from mistaking scattered awareness for local momentum. |
| **Source and campus attribution** | Needed for keep/kill decisions on paid, content, and campus ops. |

The GTM docs are explicit that vanity metrics like views and likes are secondary at best.

---

## Operating Rules

- Keep one primary bet at a time per week.
- Campus density matters more than national spread.
- Trust and copy guardrails are blocking, not optional.
- No channel gets scaled until instrumentation is decision-grade.
- Lifecycle messaging should be behavior-driven, not spam-driven.
- Paid should be treated as a gated experiment, not a launch identity.

This is reinforced both in the GTM Operating Contract and in the April-August org plan.

## Seasonal Spine

The current operating plan of record for April through August 2026 uses this sequence:

| Phase | Current job |
|-------|-------------|
| **April** | Finals utility |
| **May-June** | Pre-arrival trust |
| **July** | Social setup |
| **August** | Syllabus activation |

That sequence matters because it keeps DormWay from trying to run August-style acquisition before the product and instrumentation are ready.

## Channel Hierarchy

The GTM Playbook locks the current engine order:

| Engine | Current role |
|--------|--------------|
| **Campus distribution + in-product sharing** | Primary engine. Start with 5-8 campuses and build local loops. |
| **Short-form content** | Secondary feeder. Content should pull students into DormWay, not replace the product loop. |
| **Lifecycle messaging** | Retention support. Sunday previews, due-soon nudges, and setup recovery matter more than broadcast volume. |
| **SEO campus pages** | Support work only in this cycle, not the main engine. |
| **Paid media** | Gated experiment. Useful when attribution and readiness are real, not as a substitute for density. |

The content strategy sharpens this further: Riley's founder story is an asset, content should be entertainment-first, and campus density beats broad virality.

## Scale Gates

The current docs define two important gates.

### Instrumentation gate

Do not scale paid or large ambassador pushes until all of these are true:

- `landing_upload_started` is live and visible
- `landing_upload_completed` is live and visible
- `onboarding_started` is live across paths
- `signup_platform` is queryable
- first-action attribution is reliable by source and campus

### August gate

Do not unlock the August blitz unless both are true:

- the April `/finals` funnel proved worth scaling
- the July product-readiness checklist passed

This is a useful summary of the current GTM mentality: scale is earned by signal quality and product trust, not by calendar pressure.

## Current Paid / Media Read

The latest paid-media reference in the vault is dated **April 14, 2026**. That note gives the clearest current read:

| Channel | Best current signal | Current caution |
|---------|---------------------|-----------------|
| **TikTok** | Main Riley ad still acts like a conversion engine at $1.18 CPA in the note | Needs creative rotation discipline as spend increases |
| **Google Search** | High-intent complement to paid social | Search Partners are underperforming at $14.01 CPA and should be turned off |
| **Reddit** | Page-visit-optimized creative delivers very cheap clicks | Direct signup optimization is much weaker than page-visit optimization |
| **Snapchat** | Geo tests at UMich and UCLA show reasonable CPCs, with UMich strongest in the note | Attribution had a known `sccid` capture bug, so conversion reads need post-fix verification |
| **Meta** | Cheap awareness traffic exists in the reference data | One traffic campaign is notably less efficient than the better-performing variants |

The broader rule from the GTM docs still holds: paid is helpful only if DormWay can tie source, campus, signup, and first action together reliably.

---

## What Current GTM Is Not

- Not a broad national launch campaign.
- Not a 100-ambassador field program.
- Not paid-spend scaling before attribution is clean.
- Not SEO as the primary engine for this operating window.
- Not messaging that leans on vague AI claims.

The GTM system is trying to protect one thing above all: student trust during activation.
