# Course Deduplication Issues

Tracking course-context duplication issues and the expected fix path.

## Current Symptoms

1. Same real class can appear as multiple courses (`MKT 407`, `COMM 317`, merged labels).
2. Course color and naming can drift between Courses, Tasks, and Schedule.
3. Schedule columns/cards can split by alias variant instead of canonical identity.

## Current Root Cause Summary

1. Mixed identity keys are used across ingestion, normalization, and UI grouping.
2. Alias heuristics improve matching but are not sufficient as a final global identity model.
3. Dedupe must be tenant-scoped and term-scoped to avoid cross-institution collisions.
