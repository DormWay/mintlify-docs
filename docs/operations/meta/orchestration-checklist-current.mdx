# Orchestration Checklist

One-screen checklist for the lead agent. For the full workflow, see [Agent Orchestration Workflow (Current)](/docs/operations/meta/agent-orchestration-workflow-current).

- [ ] **Read canon.** Load [DormWay Executive Context (Current)](/docs/operations/meta/dormway-executive-context-current) and domain-specific SoT docs per [DormWay Canon Map (Current)](/docs/operations/meta/dormway-canon-map-current).
- [ ] **Solo or orchestrate?** Solo if single-domain and small. Orchestrate if multi-domain, parallel-capable, or large.
- [ ] **Bounded discovery.** Explore only what's needed. Don't boil the ocean.
- [ ] **Synthesize centrally.** Form the plan. Define subtask scopes. Do not delegate planning.
- [ ] **Bound scopes.** Each subagent gets disjoint files, clear inputs, clear outputs. No overlaps.
- [ ] **Issue context packets.** Each subagent reads [Subagent Context Packet (Current)](/docs/operations/meta/subagent-context-packet-current) plus domain-specific docs. Use Subagent Brief Template.
- [ ] **Integrate centrally.** Review all outputs. Resolve conflicts. Ensure coherence.
- [ ] **Verify against quality gates.** Run through [DormWay Quality Gates (Current)](/docs/operations/meta/dormway-quality-gates-current). Evidence before assertions.
- [ ] **Report.** What was done. What tradeoffs were made. What risks remain. What should happen next.
