## Voice & Tone

**Voice:** Smart, relaxed, human. Friendly first, credible second, never corporate.

<Tip>
**Golden Rule:** Talk like an upperclassman helping a freshman.
</Tip>

### Always Do

- Problem-first, not feature-first
- Specific over generic (Canvas, 40-page syllabus, 11pm panic)
- Honest about limitations
- Empathy over authority
- Sentence case, natural capitalization

### Never Do

- Corporate jargon (synergize, optimize, revolutionize)
- AI hype or "AI-powered" lead language
- Guilt loops or shame
- Trend slang that will age fast

<Warning>
**Allowed Trust Line (Public):** "We use AI for dates, not essays." — Use only as a trust boundary, not as a headline.
</Warning>

## Messaging Hierarchy

Every piece of copy should follow this structure:

<Steps>
  <Step title="Emotional Hook">
    Relatable pain point
  </Step>
  <Step title="Promise">
    Core value proposition
  </Step>
  <Step title="Proof">
    Trust signals
  </Step>
  <Step title="Mechanism">
    Simple how
  </Step>
  <Step title="CTA">
    Clear action
  </Step>
</Steps>

### Example: Homepage (Hybrid Hero)

| Element | Copy |
|---------|------|
| **Promise** | "College, decluttered." |
| **Mechanism** | "Drop a syllabus or connect Canvas. Your entire semester timeline builds automatically." |
| **Proof** | "2M+ deadlines tracked. 100% free for students." |
| **CTA** | "Upload anything" / "See how it works" |

### Example: For Students Page

| Element | Copy |
|---------|------|
| **Promise** | "Your entire semester. One dashboard. Free for students." |

| Purpose | Hex | Usage |
|---------|-----|-------|
| Success | `#10b981` | Completed states |
| Warning | `#f59e0b` | Due soon, attention needed |
| Error | `#ef4444` | Overdue, critical |

#### Color Hierarchy Rules

- **Primary Brand Blue**: Navigation, primary CTAs, selected states
- **Electric Accents**: Reserved for product highlights (Ace moments, new notebook, key milestone)
- **Semantic Colors**: Urgency and status only (due soon, overdue, success)
- **Course Colors**: User-defined tags—never compete with Primary Brand Blue

## Visual Identity

DormWay should feel like **high-performance clarity**, not a cheerful productivity carnival and not corporate enterprise software.

### Core Principles

- **Clarity over chaos** — Fast to scan, calm under stress, trustworthy
- **Noise-canceling focus** — Reduce friction, keep student in control

### Avoid

- Overly trendy aesthetics that age fast
- Heavy glass effects in dense content
- Decorative gradients in data-heavy views

## Workstation Density Modes

DormWay scales from **glanceable widgets** to **full workbench tools**.

<Tabs>
  <Tab title="Glance (Today)">
    **Goal:** 2-second comprehension

    - Show totals and next action above the fold
    - Default state is calm: no heavy grids
    - Expand details only on intent
  </Tab>
  <Tab title="Focus (Library)">
    **Goal:** Maximum screen utility without chaos

    - Multi-pane alignment (left nav, center work, right inspector)
    - Dense lists allowed, but columns must align
    - Keep metadata visually lighter than primary text
  </Tab>
</Tabs>

### Breakpoints

| Mode | Width | Layout |
|------|-------|--------|
| Compact | < 720px | Single column, no inspector |
| Regular | 720–1100px | Split layout, 70/30 |
| Expanded | >= 1100px | Full workbench (nav + center + inspector) |

## Data Provenance

<Info>
DormWay must show **where a deadline came from**, not just that it exists.
</Info>

### Required Pattern

Every detail view needs a **source chip**:

| Example | Format |
|---------|--------|
| From syllabus | "Syllabus PDF · Page 4" |
| From Canvas | "Canvas API · Updated 2h ago" |
| From email | "Email forward · Aug 28" |
| Uncertain | "Needs Review" indicator |

---

## Trust Level Badges

Every feature should advertise its trust mode:

| Badge | Meaning |
|-------|---------|
| **Deterministic** | Rules-based, 100% reliable |
| **Assisted** | Rules + heuristics, still deterministic output |
| **AI** | Ace or generative output |

<Note>
Trust badges must appear in any AI-generated response surface. Use small chips in headers/footers—never large banners.
</Note>

## Platform-Specific Guidance

<Tabs>
  <Tab title="Web (LockedIn)">
    - Fast scanning, minimal text, clear hierarchy
    - Avoid glass in dense views
    - Always show next action above the fold on Today
  </Tab>
  <Tab title="iOS">

    - Information density must remain readable in 1-2 seconds
    - Use DS tokens for semantic color and typography hierarchy
  </Tab>

<Warning>
**Cross-Platform Symmetry:** If a priority level, status, or color is set on Web, its visual encoding must match on iOS.
</Warning>

## Privacy & Data Ethics

<Tip>
**Pillar Statement:** Your data is your workbench. DormWay never takes ownership of the student's workspace—we facilitate mastery.
</Tip>

### Core Principles

- Student owns the workspace; DormWay provides structure
- Data access is minimal and purpose-built
- Read-only by default for LMS and calendars

### Required Trust Lines

Use these for LMS/Canvas connections:

- "Read-only access. We cannot submit assignments or drop classes."
- "We use AI for dates, not essays."
- "We only extract dates and deadlines—nothing else."

## Conflict Resolution

When sources conflict:

1. **Public landing page phrasing:** Current `dormway-lockedin` landing copy wins
2. **Voice & Positioning:** Master Guide wins for non-landing copy
3. **Product UX & visual rules:** Design Vision + UX Guidelines win
4. **If conflict remains:** Default to clarity, scanability, and student trust

## Empty States

Empty states are the first impression of the Student OS.

### Rules

- Use "Helpful Upperclassman" voice
- Offer a single clear next action
- Keep the layout calm: one headline, one sentence, one CTA

### Example Copy

| Context | Copy |
|---------|------|
| No deadlines | "No deadlines yet. Drop a syllabus and I'll build your timeline." |
| Empty notebook | "This notebook is empty. Start with a quick outline." |
