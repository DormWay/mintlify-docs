# External UI/UX Brand Refiner Handoff (Current)

## Purpose
One-page brief for external UI/UX brand refiners. This document defines DormWay's current product intent, brand voice, UX constraints, and expected deliverables.

## Source Policy (Strict)

Use only:
1. [Source of Truth Index](/docs/engineering/architecture/source-of-truth-index)
2. SoT docs listed in that index (current system behavior and IA contracts)
3. Current brand docs:
   - [DormWay-Brand-Voice-and-Positioning-Master-Guide](/docs/product/brand/dormway-brand-voice-and-positioning-master-guide)
   - [DormWay-Brand-Book](/docs/product/brand/dormway-brand-book)
4. Current design docs:
   - [DormWay-Design-Vision](/docs/product/design/dormway-design-vision)

   - [LockedIn-Schedule-UX-Guidelines](/docs/product/design/lockedin-schedule-ux-guidelines)

Do not use older launch/workback docs as primary truth.

## DormWay in One Line

DormWay is crisis-prevention infrastructure for college students: one trusted, actionable view of what is due, what is next, and where to be.

## Brand + Voice Non-Negotiables

- Student-first, never corporate.
- Problem-first messaging (panic reduction, deadline clarity, less fragmentation).
- Proof over hype (specific outcomes, trust lines, clear boundaries).
- No AI theater language or jargon-heavy claims.
- Preserve current high-confidence positioning lines:
  - "College, decluttered."
  - "Never wonder what's due."

## UX + IA Non-Negotiables

- Respect canonical 5-item IA from SoT: Today, Schedule, Tasks, Courses, Library.
- Settings remains outside main nav.
- Core productivity surfaces must feel finite, clearable, and fast to scan.
- Schedule experience must prioritize scanability, hierarchy, contrast, and alignment stability.
- Trust cues are mandatory: visible source/freshness/state clarity where relevant.

## Visual Direction Constraints

- Command-center clarity over decorative complexity.
- Solid, readable surfaces for dense productivity views; avoid noisy visual treatments.
- Color should carry meaning (status/course accents), not pure decoration.
- Preserve token-first system discipline across themes; avoid ad hoc styling drift.

## What We Need Improved

1. Narrative consistency from landing -> first-run -> daily dashboard.
2. Cross-surface hierarchy clarity (especially Today/Schedule/Courses).
3. Visual-language consistency (web + iOS directionally aligned, token-driven).
4. Conversion-page messaging that stays student-native and trust-forward.
5. Reduced style and interaction debt without adding UI complexity.

## Required Deliverables from External Refiner

1. Brand narrative architecture:
   - Message hierarchy, approved wording patterns, banned patterns.
2. Visual system refinement:
   - Color hierarchy, typography roles, spacing/elevation rules, motion principles.
3. Surface-level UX recommendations:
   - Today, Schedule, Tasks, Courses, Library, and landing sections.
4. Prioritized rollout plan:
   - Quick wins, medium changes, later changes, with rationale and tradeoffs.
5. Success criteria:
   - How we will evaluate whether the refinements improve clarity, trust, and activation.

## Evaluation Rubric (How We'll Judge Proposals)

- Fidelity to current SoT and brand contracts.
- Improvement in clarity without added cognitive load.
- Practicality of implementation in current architecture.
- Quality of reasoning and evidence behind recommendations.
- Ability to reduce drift and increase consistency across product surfaces.

## Out of Scope

- Replacing core IA contracts.
- Rebranding away from the student-first voice.
- Heavy visual novelty that harms readability or trust.
- Any strategy dependent on outdated documentation as canonical truth.
