# GTM Agentic Implementation Addendum (Spring 2026)

Date: 2026-03-03
Intent: convert the GTM playbook into an hours/days execution system with hard gates, ticket ownership, and decision-grade output.

## 1) Operating Principle (Agentic-First)
- Execution windows are measured in hours and days, not weeks.
- Every work item must fit one of these slices:
  - `4h` micro-ship (single owner, same-day verification)
  - `24h` ship (cross-functional but no external dependency)
  - `72h` ship (multi-service change with QA and rollback plan)
- No channel scale work starts until instrumentation gate is green.

## 2) Decision Gates

### Gate A: Measurement Integrity (must pass first)
- Landing upload events are complete and trusted.
- First-touch attribution is preserved and queryable by source/campus.
- Canonical `user_id` is consistent across web, mobile, and server events.

### Gate B: Activation Readability
- WFAU, activation, D7/D14/W4 visible by source and campus.
- Confidence intervals included in readouts.

### Gate C: Scale Permission
- At least 2 campuses pass activation + retention quality thresholds.
- Referral/lifecycle uplift measured with holdout controls.

## 5) Day 8-14: Controlled Scale Loop
- Run 2-3 decision-grade experiments every 24-48h cycle.
- Enforce `keep / kill / iterate` decisions with explicit thresholds.
- Expand campus effort only if Gate C remains green for consecutive readouts.

## 6) Daily Cadence (Hours/Days Rhythm)
- `09:00` 15-min triage: blockers, incidents, gate status.
- `13:00` 10-min telemetry check: event health + anomaly scan.
- `17:00` 20-min decision standup: ship state, next 24h commitments.
- `EOD` auto memo: shipped, KPI movement, decisions, next actions.

## 7) Hard Guardrails
- No net-new channel scale if Gate A is red.
- No retention claim without control cohort.
- No growth copy launch without trust QA pass.
- No ticket older than 72h without explicit re-scope.

## 8) Definition of Done (Agentic)
- Measurement gate is green and stays green for 72h.
- WFAU and retention readouts are trusted by source and campus.
- At least 5 high-impact tickets shipped from this addendum.
- Experiment loop runs on hours/days cadence, not weekly batching.
