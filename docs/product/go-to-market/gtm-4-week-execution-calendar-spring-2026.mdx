# DormWay 4-Week Execution Calendar

Start: Monday, 2026-02-23
End: Sunday, 2026-03-22
Goal: ship a measurement-ready campus growth loop, then scale only what proves out.

## Operating Constraints
- Campus scope: 5-8 campuses only.
- Primary engine: campus distribution + sharing loop.
- Secondary engine: short-form as feeder.
- Report D7, D14, and W4 (not D7 only).
- No scale until landing upload attribution is verified.

## Week 1 (Feb 23 - Mar 1): Measurement Gate + Messaging Lock

Monday
- Lock monetization narrative and copy guardrails across active GTM assets.
- Finalize canonical KPI definitions (WFAU, activation, D7/D14/W4).
- Lock 3 weekly bets (one per engine).

Tuesday
- Implement landing upload start/completion instrumentation.
- Publish one copy-correction pass (remove grade overclaim, align to manual sync language).
- Publish short-form #1 and #2 with source-tagged CTA.

Wednesday
- QA event visibility in analytics and dashboard joins.
- Ambassador script refresh for 5-8 target campuses.
- Launch campus outreach touches (quality setup help, not posting-only).

Thursday
- Publish trust-focused post (read-only, revoke anytime, free for students).
- Draft baseline memo template with confidence intervals.
- Collect objections from onboarding/support.

Friday
- Scoreboard review with raw counts + uncertainty bands.
- Keep/kill decisions for week-1 hooks.
- Confirm scale gate status (pass/fail).

Sunday
- Send Sunday preview #1 with control cohort split.
- Capture Monday behavior baseline tags.

## Week 2 (Mar 2 - Mar 8): Baseline + First Loop Tests

Monday
- Review baseline by source and campus.
- Choose next 3 bets: first-value flow, share loop, ambassador script depth.

Tuesday
- Launch first-value-before-signup test (preview week before account gate).
- Publish short-form #3 and #4 (single CTA only).

Wednesday
- Ambassador enablement call (30 min) for target campuses.
- Ship week-at-a-glance share artifact v1 (if implementation-ready).

Thursday
- Run lifecycle nudge pair: Sunday preview format + due-soon trigger.
- Add trust FAQ interaction tracking if not live.

Friday
- Scoreboard and decision review with D7 early signals.
- Promote top-performing hook only if activation quality holds.

Sunday
- Send Sunday preview #2.

## Week 3 (Mar 9 - Mar 15): Repeatability Check (First 2 Campuses)

Monday
- Validate whether at least 2 campuses show stable activation quality.
- Confirm D14 reads for earliest activated cohorts.

Tuesday
- Publish short-form #5 and #6 tied to winning campus hooks.
- Run campus-specific proof creative for strongest campuses.

Wednesday
- Ambassador recruitment sprint (quality replacements, not volume-only).
- Officer outreach sprint for org scheduling wedge.

Thursday
- Iterate lifecycle messaging using cohort results.
- Tighten trust cue placement near conversion CTAs.

Friday
- Scoreboard review: WFAU + D7/D14 + share/referral contribution.
- Decide expand/hold/deepen by campus.

Sunday
- Send Sunday preview #3.

## Week 4 (Mar 16 - Mar 22): Consolidate + Expansion Decision

Monday
- Full cohort analysis by source, campus, and first action type.
- Evaluate W4 trend on earliest cohorts where available.

Tuesday
- Publish short-form #7 and #8 only if feeder quality remains strong.
- Run referral timing refinement test.

Wednesday
- Ambassador quality audit (active vs inactive) and roster correction.
- Replace low-performing scripts.

Thursday
- Publish outcome proof post (deadline certainty, weekly clarity).
- Update objection handling snippets from real FAQs.

Friday
- Monthly decision review:
  - What moved WFAU
  - What protected or improved D14/W4
  - What failed despite high top-of-funnel metrics
  - What qualifies for expansion

Sunday
- Send Sunday preview #4.
- Publish next-cycle experiment slate.

## Weekly Output Minimums
- 3-4 short-form posts (source-tagged)
- 2 campus proof posts
- 1 trust-focused post
- 1 Sunday lifecycle send
- Ambassador touches targeted to 5-8 focus campuses
- Org/officer outreach touches tied to setup outcomes

## Weekly Review Questions
1. Which message angle improved activation without harming D14/W4?
2. Which campuses are showing real density vs one-off signups?
3. Which channel produced low-quality signups and should be cut?
4. Did lifecycle nudges improve Monday/Tuesday active behavior?
5. What single bottleneck most limited first-action completion this week?
