# Quick Start Widget

The Quick Start widget is the post-onboarding setup surface shown on the dashboard to guide first-week activation tasks.

## Code Entry Points

- Dashboard widget UI: `.repos/dormway-platform/services/dormway-lockedin/src/components/dashboard/SetupWidget.tsx`
- Reusable upload surface: `.repos/dormway-platform/services/dormway-lockedin/src/components/quick-start/QuickStartUpload.tsx`
- API route used for setup flags: `.repos/dormway-platform/services/api-router/src/routes/v2/students.routes.ts` (`GET /v2/students/me/setup-status`)

## Setup Tasks Tracked

- `schedule_uploaded`
- `syllabi_uploaded`
- `canvas_connected` (when supported for campus)
- `integrations_connected`
- Momentum tasks sourced from manual task/time-block state

## Important Behavior

- Onboarding flow no longer exports `QuickStartStep`; it is intentionally reused post-onboarding.
- Widget combines setup flags with additional onboarding-adjacent data sources (courses, term data, time-block sources).
- Dismissal/snooze state is persisted in local storage.
