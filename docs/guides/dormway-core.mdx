# Working with dormway-core

`@dormway/core` is the shared library for the DormWay platform. It centralizes all data access, domain entities, adapters, and utilities used across backend services (api-router, engine, and others).

**Location:** `services/shared/dormway-core/`
**Package name:** `@dormway/core`

<Warning>
  **ALL database access must go through dormway-core.** Never use `getAuroraPool()` and raw SQL in api-router routes or engine activities. If a factory or domain service doesn't exist for what you need, add it to dormway-core first — then use it in your application code. Violation = rewrite required.
</Warning>

## Package Structure

```
src/
├── adapters/       # Third-party integrations (Redis, Ably, Customer.io, Amplitude, Temporal)
├── database/       # Database utilities, context-graph queries
├── domains/        # Domain services (campus, city, accounts, preferences, service-data, etc.)
├── entities/       # Domain entities + factories (Campus, City, Course, Student, Syllabus, Term)
├── events/         # Context Event Bus schemas
├── llm/            # LLM integration via Portkey
├── middleware/     # Express middleware factories (auth, rate-limiter, validator)
├── utils/          # Config types, error classes, formatters, structured logger
└── aws/            # AWS SDK helpers (S3, SSM)
```

## The Entity System

Entities are domain objects with lazy-loading relationships. Always use factories for CRUD — never query the database directly in application code.

### Initialize factories at startup

```typescript
import { initializeCampusFactory, initializeCityFactory } from '@dormway/core';

// In your service startup code
await initializeCampusFactory({ pool, cacheAdapter });
await initializeCityFactory({ pool, cacheAdapter });
```

### Use factories for data access

```typescript
import { getCampusFactory } from '@dormway/core';

const factory = getCampusFactory();
const result = await factory.getById('campus-uuid');

if (result.success) {
  const campus = result.data;
  // Lazy-load relationships
  const city = await campus.getCity();
  const courses = await campus.getCourses();
}
```

### ServiceResult pattern

All factory methods return `ServiceResult<T>`. Always check `success` before accessing `data`:

```typescript
type ServiceResult<T> =
  | { success: true; data: T }
  | { success: false; error: string };

// Usage
const result = await factory.getById(id);
if (!result.success) {
  throw new NotFoundError(result.error);
}
const entity = result.data;
```

**Available entities:** Campus, City, Course, Syllabus, Term, Student

## Adapters

Adapters wrap third-party services with consistent interfaces:

```typescript
// Customer.io
import { getCustomerIOAdapter } from '@dormway/core/adapters/customerio';
const cio = getCustomerIOAdapter({ logger });
await cio.identify(userId, { campus_name: 'Cal Poly' });

// Amplitude analytics
import { getAmplitudeAdapter } from '@dormway/core/adapters/analytics';
const amp = getAmplitudeAdapter({ apiKey: process.env.AMPLITUDE_API_KEY });
await amp.trackEvent(userId, 'event_name', { prop: 'value' });

// Ably realtime
import { getAblyAdapter } from '@dormway/core/adapters/realtime';
const ably = getAblyAdapter({ apiKey: process.env.ABLY_API_KEY });
await ably.publish(`user:${userId}:updates`, { type: 'refresh' });

// Redis cache
import { getCacheAdapter } from '@dormway/core/adapters/cache';
const cache = getCacheAdapter({ redis });
await cache.set('key', value, { ttl: 300 });
```

## Structured Logger

```typescript
import { createStructuredLogger } from '@dormway/core/logger';

const logger = createStructuredLogger({
  service: 'api-router',
  environment: process.env.NODE_ENV,
  minimumLevel: 'info'
});

logger.info('system.startup', 'Service started', { port: 3001 });
logger.error('system.error', 'Request failed', error, { requestId: '123' });
```

## Error Classes

```typescript
import {
  ValidationError,
  NotFoundError,
  AuthenticationError,
  AuthorizationError,
  DatabaseError,
} from '@dormway/core/errors';

throw new ValidationError('Invalid email', { field: 'email' });
throw new NotFoundError('Campus not found', { campusId });
```

## LLM Integration

```typescript
import { callPortkeyPrompt, loadPrompt } from '@dormway/core/llm';

// Load and render a prompt template
const prompt = await loadPrompt('syllabus-extraction', {
  SYLLABUS_CONTENT: text
});

// Call LLM via Portkey gateway
const response = await callPortkeyPrompt('syllabus-extraction', {
  SYLLABUS_CONTENT: text
});
```

## Module Imports

The package supports granular submodule imports for smaller bundles:

```typescript
// Full package
import { Campus, getCampusFactory, createStructuredLogger } from '@dormway/core';

// Submodule imports (preferred for tree-shaking)
import { createStructuredLogger } from '@dormway/core/logger';
import { ValidationError } from '@dormway/core/errors';
import { getAmplitudeAdapter } from '@dormway/core/adapters/analytics';
import { getCacheAdapter } from '@dormway/core/adapters/cache';
```

```bash

# 2. Restart consumers (Mutagen syncs dist/ to VM in ~200ms)
make remote-dev-restart s=api-router
# Also restart engine if it changed:
make remote-dev-restart s=engine
```

## Adding New Code to dormway-core

### Creating a New Entity

1. Create directory: `src/entities/your-entity/`
2. Add these files:
   - `your-entity.types.ts` — Raw data and metadata types
   - `your-entity.entity.ts` — Entity class extending `BaseEntity`
   - `your-entity.factory.ts` — Factory with CRUD methods
   - `index.ts` — Exports
3. Export from `src/entities/index.ts`
4. Add type exports to `src/index.ts`

### Adding a New Adapter

1. Create directory: `src/adapters/your-adapter/`
2. Add files: `types.ts`, `your-adapter.adapter.ts`, `index.ts`
3. Export from `src/adapters/index.ts`
4. Add submodule export in `package.json` exports field

### Adding Fields to Existing Types

1. Update the type definition (e.g., `src/adapters/customerio/types.ts`)
2. Rebuild: `npm run build`
3. Update consuming code to use new fields

```typescript
import { resetCampusFactory, resetCityFactory } from '@dormway/core';

  resetCampusFactory();
```

## Troubleshooting

### "Factory not initialized"

Ensure factory initialization runs before any usage:

```typescript
await initializeCampusFactory({ pool });
// Only now will getCampusFactory() work
```

### Build errors after updating types

```bash
npm run clean && npm run build
```

### Type conflicts between domains and entities

Use prefixed imports:

```typescript
import type { ContextType as EntityContextType } from '@dormway/core';
```
