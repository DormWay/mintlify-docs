## Key Principles

- **Production is Railway** — not AWS/ECS. Never refer to ECS or Fargate for DormWay deploys.
- **Secrets are in Doppler** — never committed to git, never in `.env` files.
- **Database is Neon** — no local PostgreSQL. All DB connections use Doppler-injected `DATABASE_URL_ADMIN`.
- **Data access goes through dormway-core** — never raw SQL in api-router or engine activities.
- **dormway-lockedin hot reloads** — never restart it after code changes; use `Write` not multiple `Edit` calls.
