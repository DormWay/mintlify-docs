# Advertising Push Readiness - Backlog

Actionable tasks distilled from founder notes. Prioritize anything that breaks core flows, feels inconsistent across platforms, or violates the "2 to 3 taps from Today" rule.

## Success Criteria
- Core flows are consistent across web, iOS, macOS, and iPadOS.
- Any info a student wants is reachable within 2 to 3 taps from Today.
- Today widgets are scannable at any size and do not waste space.
- No broken widgets or dead actions are visible to users.

---

## Recently Completed (Web)
- [x] **Courses surface is unified (no tabs)**
  Outcome: single Courses view with My Courses, Canvas sync, and Term Insights sections.
- [x] **Settings removed from sidebar and accessible via profile menu**
  Outcome: navigation follows 5-item IA, settings live in top-right profile menu.
- [x] **Take Notes CTA appears when in class**
  Outcome: Today surface deep-links into the correct class notebook.
- [x] **Notes Hub shifted to course notebooks**
  Outcome: one notebook per course with auto date sections and notebook-level list grouping.

---

## Priority 0 - Must Fix Before Any Advertising Push

### Cross-Platform Parity (Web vs iOS/macOS/iPadOS)
- [ ] **Audit parity for Today, Schedule, Tasks, Courses, Notes, and overlay behavior**
  Issue: native apps are AI-generated and diverge from the web flow (quick vs deep overlay, navigation, and feature depth).
  Outcome: shared IA, consistent overlay system, and matching core actions across platforms.

### Today Page and Widgets
- [ ] **Unify setup widget visual style with other Today widgets**
  Issue: setup widget looks like a different system.
  Outcome: same typography, padding, and hierarchy as other Today widgets.
- [ ] **Remove "context detection" copy from Today unless it is actionable**
  Issue: "we detect you are at home" adds noise and no action.
  Outcome: remove or move to a debug surface.
- [ ] **Make quick actions fully functional and context-aware**
  Issue: quick actions are present but not reliably useful.
  Outcome: each action works, reflects current context, and completes the user intent.
- [ ] **Harden Today widget layout and hierarchy for all sizes**
  Issue: widgets do not always use space well or stay scannable at small and large sizes.
  Outcome: responsive grid that works in split view and ultra-wide, with clear hierarchy.
- [ ] **Week row hover shows full-day grid preview (not a small popdown)**
  Issue: current hover only shows a small list of events, not a visual schedule.
  Outcome: hover reveals a single-column day grid with time blocks and overlaps.

### Tasks and Assignments
- [ ] **Fix task completion state and ensure it persists**
  Issue: task completion is unreliable.
  Outcome: completing a task always persists and updates instantly.
- [ ] **Finish task deduplication and apply it everywhere**
  Issue: duplicate tasks appear across pages and sources.
  Outcome: a single canonical task per assignment across Today, Tasks, and Schedule.
- [ ] **Standardize text styles across color variants**
  Issue: text weight/contrast varies by color, reducing readability.
  Outcome: consistent typography and contrast for all task colors.
- [ ] **Make tasks instantly identifiable (course/personal cues)**
  Issue: unclear what a task belongs to at a glance.
  Outcome: course color or personal tag clearly labels each task.
- [ ] **Show assignment details without forcing Canvas/LMS navigation**
  Issue: users must leave DormWay to get basic instructions.
  Outcome: key instructions, points, and due details are visible in DormWay.
- [ ] **Deep link into exact LMS assignment (not just LMS home)**
  Issue: generic Canvas buttons are too slow and wasteful.
  Outcome: DormWay links open the specific assignment page.

### Courses Page UX
- [x] **Replace tabbed layout (My Courses / Canvas / Term Insights) with single Courses surface**
  Issue: critical intelligence is split across tabs and easy to miss.
  Outcome: one Courses view with expandable course details and overlay/deep views.
- [ ] **Surface AI insights inline (Academic Pulse, workload, risks, synergy)**
  Issue: term insights are buried and detached from course context.
  Outcome: insights appear directly in each course detail.

### Schedule Page Reliability and Interaction
- [ ] **Clean up overlapping events layout**
  Issue: overlaps are messy and hard to parse.
  Outcome: consistent overlap stacking with readable labels.
- [ ] **Fix add-event menu position and background dimming**
  Issue: menu opens in the wrong place and dims unnecessarily.
  Outcome: menu opens anchored to the trigger without unwanted dimming.
- [ ] **Resolve schedule rules fetch error state**
  Issue: UI shows "false failed to fetch schedule rules".
  Outcome: accurate empty state with a clear way to add rules.
- [ ] **Right rail behavior adapts to width and avoids tall empty space**
  Issue: right rail is too wide or drops below and wastes vertical space.
  Outcome: responsive rail that collapses, docks, or hides based on width.
- [ ] **Smart Schedule suggestions appear on-grid as ghost blocks**
  Issue: suggestions are hidden in the rail and hard to evaluate.
  Outcome: suggestions render as draggable, resizable ghost blocks on the grid.
- [ ] **Plan flow respects due dates and user active hours**
  Issue: planning offers times after due dates and outside waking hours.
  Outcome: planning only suggests valid windows based on due date and user hours.

### Feature Gating
- [ ] **Hide broken widgets behind flags (Notes, Viewer Panel, Lecture Recording)**
  Issue: users can add widgets that do not work.
  Outcome: only stable widgets appear; experimental widgets are gated.

## Priority 1 - Strongly Recommended for Pre-Push Polish

### Tasks Page UX and Planning
- [ ] **Improve task list layout to avoid a single full-width column**
  Issue: tasks take excessive horizontal space and reduce scanability.
  Outcome: denser, clearer task list with hierarchy by importance.
- [ ] **Show due date on the planning week view**
  Issue: planning UI does not show the due date inside the plan grid.
  Outcome: due dates appear on the week view and constrain plan slots.
- [ ] **Use task intelligence to auto-break large tasks (Goblins Tools style)**
  Issue: large tasks feel overwhelming and lack structure.
  Outcome: DormWay proposes a step breakdown using LMS or syllabus data.
- [ ] **Show standardized importance/weight for assignments**
  Issue: grading scales vary and users cannot gauge impact quickly.
  Outcome: a normalized importance score based on syllabus data.
- [ ] **Make task creation smarter and faster (ACE-supported)**
  Issue: task creation is slow and not assisted enough.
  Outcome: natural language or ACE-assisted task creation with confirmations.

### Quick Actions and ACE
- [ ] **Command palette for quick actions (Command-K)**
  Issue: quick actions lack a fast power-user entry point.
  Outcome: command palette routes questions to ACE and actions to shortcuts.

### Settings and Profile Menu
- [x] **Move settings to profile menu and refine account/integrations layout**
  Issue: settings and account clutter the main nav.
  Outcome: settings live under profile with improved animation and grouping.

---

## Priority 2 - Post-Push and Long-Term Enhancements

### Notes and Library (Non-MVP)
- [x] **Notebook per class with date sections**
  Issue: notes are fragmented across separate docs and hard to browse.
  Outcome: each class has a single notebook with auto-added daily sections.
- [x] **"Take Notes" button appears when user is in class**
  Issue: note-taking entry is not context-aware.
  Outcome: contextual button launches the correct class notebook.
- [ ] **Add notebook date index + collapsible sections**
  Issue: large notebooks are hard to navigate by date.
  Outcome: jump list (by date) and optional collapsible sections for long semesters.
- [ ] **Integrate lecture recordings, overview, and transcripts into notebooks**
  Issue: recording features exist but are not surfaced in notes.
  Outcome: notebook embeds recordings, summaries, and transcripts.
- [ ] **Allow capture of slide images into notes (smart PNG)**
  Issue: users cannot quickly save in-class visuals.
  Outcome: photo capture generates a clean PNG and inserts into notes.
- [ ] **Explore freeform canvas mode for branching notes**
  Issue: linear notes do not suit ADHD/nonlinear thinking.
  Outcome: optional spatial canvas for branching concepts.

### Schedule Voice Actions
- [ ] **Voice memo to ACE for schedule changes**
  Issue: scheduling changes require manual typing/dragging.
  Outcome: voice input creates suggestions and confirms placements.

### Today Widget Refinements (Nice to Have)
- [ ] **Improve setup progress widget and other non-critical widgets**
  Issue: quality varies and not aligned with new Today system.
  Outcome: consistent polish for all widgets.
