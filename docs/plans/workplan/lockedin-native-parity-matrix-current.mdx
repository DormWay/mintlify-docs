# LockedIn Native Parity Matrix (Current)

## Status Legend
- `Aligned`: behavior and IA are materially aligned.
- `Partial`: overlap exists, but one platform has meaningful additional capability.
- `Diverged (intentional)`: UX model differs by platform by design; equivalent outcomes still required.
- `Blocked`: parity depends on unresolved canonical decisions/contracts.
