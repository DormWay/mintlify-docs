# Library Knowledge Hub Plan

The Library is a **knowledge-first** surface. Courses are a primary lens, not the only lens. The Library should feel like a **Digital Backpack** where students can dump knowledge fast, then structure it later.

**Boundary:** Library = Knowledge (notes, files, lectures). Tasks page = Action. The Library can inform Tasks, but it should not become a task list.

---

## Summary (Current Reality)
- The web Library is course-oriented today: term groups + course sidebar + quick jump grid + search across notes/files/lectures.
- Notes auto-insert **term + day headings** for class notes in the editor, with a hierarchical jump nav (Term -> Day).
- Canonical notebooks are now resolved via a dedicated endpoint (`/v2/notes/notebook`) for course notebooks.
- Files and lectures are only **recent** in the course panel; the Library is not yet comprehensive for materials.
- A Library widget exists on Today (lecture-focused), not the primary Library surface.

---

## Target IA (Knowledge-First)
**Left Rail = Universal Content Navigator**
1) **Active / Pinned** - quick access to what you are working on now.
2) **Inbox (Unsorted)** - fast dump zone for files/notes/lectures without context.
3) **Personal** - Journal, Ideas, Plans, Personal Vault (non-course knowledge).
4) **Courses (By Term)** - structured academic notebooks, collapsible by semester.
5) **Global Collections** - All Files, All Lectures, Unsorted.

**Main Panel**
- Course notebook + materials panel when a course is selected.
- Inbox or Global Collections view when selected from the rail.

---

## Goals
1) **Canonical notebooks** for each topic (Course or Personal).
2) **Term -> Day navigation** inside notebooks for fast class-day access.
3) **Comprehensive materials** access (files + lectures) inside the Library page.
4) **Long-term use** across semesters via Personal notebooks + collapsed past terms.
5) **Left rail usability**: width clamping, padding from DashboardSidebar, clean mobile drawer.

## Non-goals
- No task list inside Library.
- No heavy planner drag/drop in early phases.
- No full navigation redesign.

---

## Phase Plan

### Phase 1 - Notebook Mastery (Canonical + Term -> Day)
**Objective:** One master notebook per topic (course or personal), with visible hierarchy.

- **Canonical notebooks**
  - Add `noteKind: notebook` (or tags-based flag) to identify master notebooks.
  - Add server query for notebook by topic (`GET /notes/by-topic?...`).
  - Replace recent-notes heuristics with canonical notebook lookup.
  - **Status:** Implemented `/v2/notes/notebook` and course notebook resolution in Library; still missing personal notebooks + backfill.

- **Hierarchical navigation**
  - Insert **term headings** (e.g., `## Winter 2026`) if missing.
  - Insert **day headings** under term (e.g., `### Jan 13`).
  - Add a **Notebook Section Nav** that collapses by term and jumps to days.
  - **Status:** Term + day headings inserted in NotesWorkspace; right-rail nav renders hierarchical Term -> Day.

**Touchpoints**
- `services/dormway-lockedin/src/components/notes/NotesWorkspace.tsx`
- `services/dormway-lockedin/src/components/library/LibraryCoursePanel.tsx`
- New: `services/dormway-lockedin/src/components/library/NotebookSectionNav.tsx`

---

### Phase 2 - Left Rail Expansion (Active + Inbox + Personal + Courses)
**Objective:** The rail reflects knowledge-first navigation.

- Add **Active / Pinned** at the top for quick access.
- Add **Inbox** at top for unsorted materials.
- Add **Personal** notebooks (Journal, Ideas, Plans).
- Keep **Courses by Term**, but collapse older terms.
- Add **Global Collections** (All Files / All Lectures / Unsorted) as quick filters.
- Apply **width clamp** and **padding** from DashboardSidebar.

---

### Phase 3 - Integrated Materials
**Objective:** Students access everything without leaving Library.

- **Files**: full list (filters: type/date/syllabus), upload/sync CTA.
- **Lectures**: full list with status + transcript access.

---

### Phase 4 - Search Depth + Context Links (Optional)
**Objective:** Make knowledge discoverable and connected to action.

- Full-text search across all notes/files/lectures.
- Lightweight "Link to Task" affordance (context only, no task UI in Library).

---

## Inbox Behavior (Unsorted)
- Anything without a course/topic mapping lands in Inbox.
- Inbox is **always visible** and should feel like a Downloads folder.
- No blocking prompts on upload; triage happens later.

---

## Open Questions
1) **Notebook scope:** one notebook per course across all terms, or per term?
   - Recommendation: **one notebook per course**, segmented by term headings.
2) **Personal notebooks:** predefined (Journal/Ideas/Plans) vs user-created?
   - Recommendation: start with predefined + allow custom later.
3) **Inbox ownership:** should it show notes, files, and lectures or only files?
   - Recommendation: include all unsorted items.

---

## Immediate Next Step
Finish **Phase 1**: backfill or promote existing notes into canonical notebooks, and surface Personal notebooks inside Library. Then proceed to Phase 2 (Inbox + Personal + Courses rail + collections completeness).
