# Webhooks

DormWay now has two webhook directions:

- inbound webhooks from Ambassador
- outbound webhooks managed in admin and delivered to tools like n8n, Slack, or Google Sheets

## Inbound: Ambassador

| Environment | URL |
|-------------|-----|
| Production | `https://relay.dormway.app/webhooks/ambassador` |
| Staging | `https://relay-staging.dormway.app/webhooks/ambassador` |
| Local dev | `http://localhost:3001/webhooks/ambassador` |

The handler lives at `api-router/src/routes/webhooks/ambassador-routes.ts`.

### Signature Verification

Ambassador signs each webhook with HMAC-SHA256:

| Header | Value |
|--------|-------|
| `x-ambassador-signature` | `HMAC-SHA256("{timestamp}.{rawBody}", secret)` |
| `x-ambassador-timestamp` | Unix timestamp |

The webhook secret is stored as `AMBASSADOR_WEBHOOK_SECRET`.

### Core inbound event families

| Event family | DormWay behavior |
|--------------|------------------|
| Commission events | Update local commission records and status |
| Referral events | Track funnel and referral outcomes |
| Ambassador profile events | Log external platform changes |

## Outbound: Admin-Managed Deliveries

DormWay can now dispatch outbound webhook POSTs on platform events through the shared webhook domain service.

### Delivery model

```text
Platform event
  -> WebhookService.dispatchEvent(...)
  -> active subscriptions for matching events
  -> POST to subscriber URL
```

### Supported outbound events

| Event | Typical trigger |
|-------|-----------------|
| `user.signup` | Clerk `user.created` |
| `user.onboarding_complete` | onboarding workflow completion |
| `syllabus.uploaded` | syllabus upload API |
| `syllabus.processed` | syllabus processor completion |
| `canvas.connected` | Canvas connection routes |
| `schedule.imported` | schedule import completion |

### Delivery contract

- HTTP method: `POST`
- body: JSON
- optional shared secret: sent in `X-Webhook-Secret`
- timeout: 5 seconds
- delivery style: fire-and-forget, never block the primary product action

### Admin management

Subscriptions live in `webhook_subscriptions` and are managed in `dormway-admin` at `/webhooks`.
