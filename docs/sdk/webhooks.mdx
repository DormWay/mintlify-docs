# Webhooks

DormWay currently ingests webhooks from the **Ambassador** referral platform (getambassador.com). These webhooks notify DormWay when commissions change state or referral events occur.

## Webhook Endpoint

| Environment | URL |
|-------------|-----|
| Production | `https://relay.dormway.app/webhooks/ambassador` |
| Staging | `https://relay-staging.dormway.app/webhooks/ambassador` |
| Local dev | `http://localhost:3001/webhooks/ambassador` |

The handler lives at `api-router/src/routes/webhooks/ambassador-routes.ts`.

## Authentication & Signature Verification

Ambassador signs each webhook with HMAC-SHA256:

| Header | Value |
|--------|-------|
| `x-ambassador-signature` | `HMAC-SHA256("{timestamp}.{rawBody}", secret)` |
| `x-ambassador-timestamp` | Unix timestamp (seconds) |

The webhook secret is stored in Doppler as `AMBASSADOR_WEBHOOK_SECRET`. Requests with timestamps older than 5 minutes are rejected to prevent replay attacks.

### Verifying a Signature Locally

```bash
TIMESTAMP=$(date +%s)
BODY='{"event_type":"commission.created","data":{}}'
SECRET="your-webhook-secret"

SIGNATURE=$(echo -n "${TIMESTAMP}.${BODY}" | openssl dgst -sha256 -hmac "${SECRET}" | cut -d' ' -f2)

curl -X POST http://localhost:3001/webhooks/ambassador \
  -H "Content-Type: application/json" \
  -H "x-ambassador-signature: ${SIGNATURE}" \
  -H "x-ambassador-timestamp: ${TIMESTAMP}" \
  -d "${BODY}"
```

## Event Types

### Commission Events

| Event | DormWay Action |
|-------|----------------|
| `commission.created` | Creates `ambassador_commissions` record |
| `commission.pending` | Updates status to `pending` |
| `commission.approved` | Updates status to `approved` |
| `commission.paid` | Updates status to `paid`, sets `paid_at` |
| `commission.rejected` | Updates status to `rejected` |
| `commission.cancelled` | Updates status to `rejected` |

### Referral Events

| Event | DormWay Action |
|-------|----------------|
| `referral.created` | Logs event for funnel analytics |
| `referral.converted` | Verifies and records referral in local DB |

### Ambassador Profile Events

| Event | DormWay Action |
|-------|----------------|
| `ambassador.created` | Logs event |
| `ambassador.updated` | Logs event |

## Retention Milestones

Ambassador commissions are triggered by DormWay when a referred student hits retention milestones:

| Milestone | Event Type | Commission |
|-----------|------------|-----------|
| Onboarding complete | `onboarding_complete` | $5 |
| Day 7 retained | `day_7_retained` | $2 |
| Week 4 retained | `week_4_retained` | $3 |

Max payout per fully retained referral: **$10**

## Custom Fields (Ambassador → DormWay Mapping)

| Field | Usage |
|-------|-------|
| `custom1` | Campus context ID (reserved for metadata) |
| `custom2` | Onboarding complete counter |
| `custom3` | Day-7 retained counter |
| `custom5` | Week-4 retained counter |

`custom4` is intentionally unused for retention counters.

## Database Tables

### ambassador_commissions

Stores commission records received via webhook:

| Column | Type | Notes |
|--------|------|-------|
| `id` | UUID | Primary key |
| `ambassador_id` | UUID | FK to accounts |
| `commission_id` | string | External Ambassador ID |
| `amount_cents` | integer | Amount in cents |
| `currency` | string | Default: `USD` |
| `status` | enum | `pending`, `approved`, `paid`, `rejected` |
| `event_id` | UUID | Associated referral event |
| `paid_at` | timestamp | Set when status = `paid` |

### referral_events

Tracks referral relationships:

| Column | Type | Notes |
|--------|------|-------|
| `referrer_id` | UUID | Ambassador's account ID |
| `referred_id` | UUID | Referred user's account ID |
| `event_type` | enum | `onboarding_complete`, `day_7_retained`, `week_4_retained` |
| `status` | enum | `pending`, `synced`, `failed` |

## Configuring in the Ambassador Dashboard

1. Navigate to **Settings > Webhooks**
2. Add New Webhook with URL: `https://relay.dormway.app/webhooks/ambassador`
3. Set the secret (must match `AMBASSADOR_WEBHOOK_SECRET` in Doppler)
4. Enable all commission events + `referral.created` + `referral.converted`
5. Use "Send Test" to verify a `200` response

## Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| 401 Unauthorized | Invalid signature | Verify webhook secret matches Doppler |
| 401 Timestamp expired | Clock skew > 5 min | Sync server clock |
| 500 Internal Error | Database issue | Check api-router logs |
| No webhook received | Network / firewall | Verify endpoint is publicly reachable |
