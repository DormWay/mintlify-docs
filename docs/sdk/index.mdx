# SDK & Integrations

DormWay connects to external systems to bring a student's academic life into one place. This section covers the four primary integration surfaces.

<CardGroup cols={2}>
  <Card title="Canvas LMS" icon="graduation-cap" href="/sdk/canvas-lms">
    ICS feed parsing and course sync for Canvas, Moodle, Blackboard, and other LMS platforms.
  </Card>
  <Card title="Webhooks" icon="webhook" href="/sdk/webhooks">
    Inbound webhook ingestion for the Ambassador referral platform — commission and referral lifecycle events.
  </Card>
  <Card title="Realtime Events" icon="bolt" href="/sdk/realtime-events">
    Ably-powered pub/sub channels for live dashboard updates, Canvas grade notifications, and student presence.
  </Card>
  <Card title="Plugin SDK" icon="puzzle-piece" href="#">
    A plugin SDK for embedding DormWay context into third-party tools is in development. Documentation coming soon.
  </Card>
</CardGroup>

## Integration Summary

| Integration | Direction | Protocol | Purpose |
|-------------|-----------|----------|---------|
| Canvas / LMS | Inbound | ICS (iCalendar) | Import course schedules and assignment due dates |
| Ambassador | Inbound | HTTPS Webhooks | Commission and referral lifecycle events |
| Ably Realtime | Outbound (push) | WebSocket / SSE | Live dashboard updates and grade notifications |
| Plugin SDK | TBD | TBD | Third-party tool embedding (in development) |

## Architecture Note

All external integrations flow through the **api-router** service (port 3001) and are orchestrated by **Temporal workflows** in the engine service (port 3030). The ably-relay service (port 3032) bridges device telemetry from mobile clients back into Temporal workflows.
