# SoT (Current)

This section surfaces the engineering pages whose canonical source of truth now lives in `obsidian-vault/Engineering`.

The rule is simple:

- only docs marked `status: current` belong in this set
- draft SoTs stay in Obsidian until they are promoted
- if an older implementation note and a current SoT disagree, the current SoT should usually win

<Note>
  Mintlify now tracks current engineering sources from **both** `obsidian-vault/DormWay` and `obsidian-vault/Engineering`.
</Note>

## What Is Still Out of Scope

- Draft SoTs like WidgetKit, iOS UI patterns, Growth Programs & Referral Attribution, and LockedIn rendering strategy are not in this section yet.
- Generated entity and domain references are still useful, but they are not treated as hand-authored SoTs.

That keeps this section focused on the current, promoted contracts rather than every architecture note in the vault.
