# BrainGains RAG and AI Crews

BrainGains is DormWay's document intelligence layer. It covers document ingestion, Ragie indexing, syllabus-derived structured outputs, chat history, and the course and student `service_data` artifacts that other systems consume.

## Core Responsibilities

- ingest uploaded study documents
- index searchable content in Ragie
- process syllabi into structured outputs
- store course and term insights in `service_data`
- provide context for Ace chat and other downstream reasoning features

## Important Invariants

- `braingains_documents` tracks processing status from `pending` to `indexed` or `failed`
- API upload paths index with Ragie first, then link results during workflow processing
- AI policy must block indexing and chat behavior for users with AI disabled
- syllabus dedup is hash-based and version-gated through `SYLLABUS_PARSER_VERSION`
- engine-side generic RAG querying is intentionally not the production path; production queries must come through API routes

## Ragie Partition Rules

- user scope: `user_<id>`
- course scope: `course_<id>`
- org scope: `org_<id>`
- IDs are sanitized to lowercase-safe keys
- course-scoped Ace flows can fall back to the user's partition when needed

## Syllabus Processing Contract

When a syllabus is uploaded:

1. the file is stored and indexed
2. `syllabusProcessor` produces structured outputs
3. course-context `service_data` records are written
4. insight documents can be stored separately from the raw syllabus
5. the syllabus may be pushed to enrolled classmates through explicit dependency wiring

## Stored Outputs

### Course-context `service_data`

- `processed_syllabus_crew`
- `braingains_syllabus_structure`
- `braingains_syllabus_insights`
- `braingains_prioritized_assignments`
- `braingains_highlighted_policies`
- `braingains_course_costs`

### Student-context `service_data`

- `braingains_semester_workload_analysis`
- `braingains_schedule_conflict_detection`
- `braingains_cross_course_insights`
- `braingains_semester_planning`
- `braingains_early_warnings`

## Chat and Retrieval

BrainGains chat storage is separate from the indexing pipeline:

- `braingains_chats`
- `braingains_chat_messages`

The chat layer persists sessions and messages, while retrieval uses Ragie plus scoped filters and context assembled in the API layer.
