# WIDGET_MIGRATION_GUIDE

Practical guide for migrating iOS widget implementations to the v2 widget envelope model.

## Migration Checklist

1. Move data fetches to `WidgetAPIService` (`/v2/widgets/{type}`).
2. Define typed response/content models for the target widget.
3. Keep size/content-level behavior explicit for small vs large layouts.
4. Preserve graceful degradation when v2 fields are absent.
5. Validate payload shape against live endpoint responses before shipping.

## Verification Targets

- Widget renders correctly at compact and expanded sizes.
- No regressions in widget ordering, IDs, or layout constraints.
- API responses decode without fallback-to-legacy hacks.
