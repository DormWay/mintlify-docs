# WidgetAPIService

`WidgetAPIService` is the iOS service layer that fetches widget envelopes from v2 widget endpoints.

## Code Source of Truth

- Service implementation: `.repos/ios-clean/Packages/DWServices/Sources/DWServices/WidgetAPIService.swift`

## Responsibilities

- Fetch single widget envelopes from `/v2/widgets/{type}`.
- Fetch batch envelopes from `/v2/widgets/batch?types=...`.
- Track per-widget loading/error/last-update state.
- Persist and reuse per-widget ETags for conditional fetch behavior.
- Decode typed payloads with `V2WidgetResponse<T>` / `V2BatchWidgetResponse`.

## Why It Matters

- Keeps iOS aligned with the web widget-envelope contract.
- Avoids BFF-specific flattening assumptions.
- Centralizes caching and fetch behavior for widget consumers.
