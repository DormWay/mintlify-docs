# Onboarding Flow - Source of Truth

## Overview

The onboarding flow collects essential information from new users to personalize their DormWay experience. The flow is designed to be:
- **No scrolling** - Each step fits on screen
- **Clear purpose** - WHY text explains each ask
- **Skippable where appropriate** - Housing is optional
- **Fast** - 4 steps total, ~60 seconds to complete

## Steps

### 1. Welcome Step
**File:** `src/components/onboarding/steps/WelcomeStep.tsx`

**Collects:**
- Academic year (Freshman, Sophomore, Junior, Senior, Graduate, Other)

**Purpose:** Tailor workload and deadline recommendations to the user's year.

### 2. Campus Step
**File:** `src/components/onboarding/steps/CampusStep.tsx`

**Collects:**
- Campus ID and name

**Features:**
- Search-first UX (typeahead with max 5 results)
- Email domain auto-detection (e.g., @umich.edu → University of Michigan)
- Location detection as secondary option
- Celebration animation on selection

**Purpose:** Customize schedule, deadlines, and campus resources.

### 3. Housing Step
**File:** `src/components/onboarding/steps/HousingStep.tsx`

**Collects:**
- Housing type: On-campus or Off-campus
- (Optional) Dorm selection and room number

**Features:**
- **Skippable** - "Skip for now" button
- Collapsible dorm selection (only shows after on-campus selected)

**Purpose:** Connect users with neighbors and campus community (future Crews feature).

### 4. Complete Step
**File:** `src/components/onboarding/steps/CompleteStep.tsx`

**Collects:**
- Analytics opt-in (pre-checked)
- Email updates opt-in (unchecked)

**Features:**
- Compact summary chips showing selections
- Data transparency footer
- Privacy/Terms links
- "Go to Dashboard" CTA

## Form Data Structure

```typescript
interface OnboardingFormData {
  // Campus
  campus: string;      // Campus ID
  campusName: string;  // Display name

  // Academic
  year: string;        // Freshman, Sophomore, etc.

  // Housing
  housing: 'on-campus' | 'off-campus' | '';
  dormId: string;
  dormName: string;
  roomNumber: string;

  // AI (defaults applied, not shown in onboarding)
  aiEnabled: boolean;  // true
  tone: string;        // 'friendly'
  personality: string; // 'friend'

  // Consent
  allowAnalytics: boolean;
  updatesEmail: boolean;
}
```

## Removed: Personality Step

The Personality Step ("Set the vibe") was **removed** from onboarding as of 2026-03-14.

**Rationale:**
- Added friction without clear value
- Most users stuck with defaults anyway
- AI personality can be customized in Settings post-onboarding

**Defaults Applied:**
- `aiEnabled: true`
- `tone: 'friendly'`
- `personality: 'friend'`
- This maps to the "Study Buddy" preset

## Design System

All steps use brandbook-compliant styling:
- **Borders:** `border border-[var(--ds-border-1)]` (subtle)
- **Hover:** `hover:border-[var(--ds-border-2)]`
- **Cards:** `bg-[var(--ds-soft-card-bg)]`
- **Surfaces:** `bg-[var(--ds-surface-1)]`
- **Icons:** Lucide React only (no emojis)
