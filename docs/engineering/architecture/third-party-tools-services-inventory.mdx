## Core Infrastructure

| Service | Purpose | Key Features | Status | Cost Model |
|---------|---------|--------------|--------|------------|
| **Neon Postgres** | Primary DB | • Serverless Postgres<br>• Branching<br>• RLS with `dormway_api` role | ✅ Active | Usage-based |
| **Redis (ElastiCache)** | Cache | • Low-latency cache<br>• Session + graph caches | ✅ Active | Per node-hour |
| **Temporal** | Workflow Engine | • Distributed workflows<br>• Long-running processes<br>• Retry handling<br>• Event sourcing | ✅ Active | Self-hosted |
| **Zuplo** | API Gateway | • Routing to api-router<br>• API keys<br>• Edge auth | ✅ Active | Per request |
| **S3** | Object Storage | • File uploads<br>• Signed URLs | ✅ Active | Per GB |
| **Docker** | Containerization | • Local development<br>• Consistent deployments<br>• Service isolation | ✅ Active | Free |
| **Doppler** | Secrets Management | • Environment sync<br>• Access control<br>• Audit logging | ✅ Active | Per user |
| **Cloudflare** | DNS & CDN | • Domain management<br>• SSL certificates<br>• DDoS protection | ✅ Active | Per domain |

## Service Redundancy & Fallbacks

| Primary Service | Fallback Option | Switch Time | Data Migration |
|----------------|-----------------|-------------|----------------|
| **PortKey** | Direct API calls | < 5 min | Not needed |
| **Customer.io** | Direct APNS | < 30 min | Export user tokens |
| **Ably** | Socket.io | < 2 hours | Minimal changes |
| **Neon** | Self-hosted Postgres | < 4 hours | Database dump |
| **Vectara** | Pinecone | < 1 day | Re-index documents |

## Security & Compliance

| Aspect | Tools Used | Compliance | Notes |
|--------|------------|------------|-------|
| **Data Encryption** | Neon, S3, Doppler | AES-256 | At rest & in transit |
| **Access Control** | Postgres RLS + Zuplo + api-router | RBAC | Row-level security (`dormway_api` role) |
| **Secrets Management** | Doppler | SOC 2 | Automated rotation |
| **API Security** | Zuplo | API keys + Clerk JWT pass-through | Gateway + app rate limits |
| **Privacy** | All services | FERPA ready | Student data protected |
