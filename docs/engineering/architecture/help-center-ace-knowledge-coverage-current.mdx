# Help Center & Ace Knowledge Coverage (Current)

## Summary
DormWay needs a reliable, self-serve documentation surface for core student flows (schedule, syllabus, Canvas, planning). Today, the Help Center seed doc exists but does not fully cover Canvas or define how Ace should answer product "how-to" questions. This document defines the coverage map, adds concrete implementation references, and outlines how to make Ace aware of Help Center content.

## Goals
- Ensure students can complete core setup actions without live support.
- Keep help content aligned with actual UI paths and API behavior.
- Make Ace capable of answering "how do I..." questions by indexing product help docs.
- Provide clear implementation references for future agents.

## Non-goals
- Replace product onboarding (see [Onboarding Discovery & First-Run Strategy (Current)](/docs/engineering/architecture/onboarding-discovery-first-run-strategy-current)).
- Redesign the Ace UI or introduce new chat providers.
- Document every feature; focus on the top setup and data ingestion flows.

## Ace Help Knowledge (Gap + Path Forward)

### Gap
Ace is not currently trained on (or indexed with) product Help Center docs. It answers questions based on:
- Structured data (tasks, assignments, schedules) via `ace-context-aggregator.ts`.
- Ragie documents indexed from user and course content.

There is no ingestion path that indexes Help Center docs into Ragie, and there is no explicit "help" scope in the Ace query flow.

### Path Forward (Recommended)
1. **Create a Help Center corpus in Ragie**
   - Partition: `org_dormway` (or `org_help`), using the existing partition rules in `ace-llm.ts`.
   - Document type: `help_center` with metadata tags (feature, platform, last_updated).
   - Source files: `Product/Features/Documentation/Help Center/*`.
2. **Add a Help scope to Ace**
   - Extend Ace scope to support `help` or `org` queries that include the Help Center partition.
   - Suggested heuristic: if message matches "how do I", "where do I", or "connect" + feature name, include help partition.
3. **Ingestion pipeline**
   - Use `storeGenericDocumentInRagie` in `ragie.activities.ts` to index Help Center docs on publish.
   - Trigger indexing from a docs build hook or a lightweight CLI script (keeps docs and Ace in sync).
4. **User-facing fallback**
   - Until help docs are indexed, Ace should surface a "View Help Center" CTA for product questions.

## Acceptance Criteria
- Help Center includes Canvas connection/sync instructions aligned to current UI.
- Students can complete Schedule, Syllabus, and Canvas setup without support.
- Ace can answer at least 80% of "how do I" product questions using Help Center docs (after ingestion is added).
- Help Center doc updates propagate to Ace within 24 hours.

## Known Risks
- Help content can drift if UI labels change; keep references tied to `NAVIGATION_ROUTES` and component names.
- Without ingestion, Ace answers for product "how-to" will be inconsistent or generic.
