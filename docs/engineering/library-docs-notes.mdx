# Library (Docs and Notes)

Library is DormWay's current web knowledge hub for files and notes. It is the primary surface, even though older deep links to Docs and Notes Hub still exist.

<Note>
  Current route contract: `/dashboard/library` is primary. `/dashboard/documents` and `/dashboard/notes-hub` remain supported mainly for legacy entry and deep-link compatibility.
</Note>

---

## Core Invariants

| Topic | Current truth |
|-------|---------------|
| **Primary surface** | Library is the main hub for files and notes. |
| **Sidebar model** | Notes is not its own main sidebar tab. |
| **Notes sync** | Uses `/notes/*` endpoints with a durable offline queue and revision tracking. |
| **Document source** | File listing uses BrainGains document APIs. |
| **Course scoping** | Course-aware filtering is driven by course context UUIDs. |
| **Notebook indexing** | Course notebook/topic lookups depend on indexed notebook metadata. |

The main design intent is that Library should feel like one knowledge surface even though some of the underlying routes were built at different times.

---

## Notebook Contract

The current SoT is unusually specific here:

- one canonical notebook per course
- session notes live inside that notebook instead of as separate per-day files
- term and day headings are auto-inserted for class notes
- canonical notebook metadata uses course-topic fields rather than ad hoc note labels

That keeps notes course-aware without turning them into a flat pile of personal docs.

---

## Surface Map

| Surface | Current role |
|---------|--------------|
| **Library** | Main knowledge-first destination with course grouping, search, and course notebook panels |
| **Docs** | Legacy file-focused route still kept for deep links |
| **Notes Hub** | Legacy editor-focused route still kept for deep links |
| **`/dashboard/notes`** | Redirect path, not the canonical landing page |

The north-star direction is still unified Library behavior: recent docs, recent notes, study-view defaults, and shared search rather than separate product islands.

---

## Current Known Gaps

The current SoT still calls out a few open issues:

- unified docs-plus-notes search is not fully there yet
- some note deep links lose context during redirect flows
- doc-linked notes are still filtered client-side in places
- Study View does not yet honor every note-specific deep-link case

So this page is not saying the surface is complete. It is saying the route ownership, notebook structure, and sync behavior are now stable enough to treat as the current contract.
