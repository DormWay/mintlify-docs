# Campus Metadata View

`CampusMetadataView` is the admin-facing component for visualizing enriched campus metadata in the DormWay admin console.

## Code Entry Points

- Component: `.repos/dormway-platform/services/dormway-admin/src/pages/campuses/components/CampusMetadataView.tsx`
- Primary usage:
  - `.repos/dormway-platform/services/dormway-admin/src/pages/campuses/index.tsx`
  - `.repos/dormway-platform/services/dormway-admin/src/pages/campuses/show.tsx`

## Data Surfaces Rendered

- `campusMetadata` (housing, dining, transportation, athletics, resources, timezone, LMS metadata)
- `perplexityData` (news/events/recreation/dining enrichments)
- `contextMetadata` fallback fields
- Enrollment and location metadata (`city`, `state`, `latitude`, `longitude`)
- Feature-flag-driven derivation (`use_canvas_sync` influences LMS labeling)

## UX Behavior

- If no enrichment payload exists, the component renders an informational alert instructing admins to run enrichment.
- Housing supports expandable detail rendering.
- Cards aggregate high-level campus overview with nested structured metadata details.
