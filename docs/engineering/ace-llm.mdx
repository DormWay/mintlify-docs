# Ace LLM

Ace is DormWay's assistant runtime, not the ingestion layer. It sits on top of structured student data, BrainGains retrieval, and DayPlan context to answer questions and trigger task actions.

## Core Pipeline

| Stage | Responsibility |
|-------|----------------|
| chat route | receive request, load history, enforce AI policy |
| context aggregation | fetch current time, campus, tasks, assignments, DayPlan, and term signals |
| retrieval | query Ragie with scoped partitions |
| model call | run the configured provider through the Ace pipeline |
| tool execution | create, complete, or list tasks when the model requests tools |

## Rich Context Contract

Ace context prioritizes:

1. current date and time
2. campus and conditions
3. structured academic data
4. term-level analysis
5. document snippets from retrieval

The aggregator uses parallel fetching with graceful degradation rather than failing the whole chat if one source is unavailable.

## Tooling

Current built-in tools:

- `create_task`
- `complete_task`
- `list_tasks`

Tool execution goes through dormway-core entities rather than raw SQL or ad hoc route-side mutation logic.

## Relationship to Other Systems

- BrainGains handles document ingestion and indexing
- DayPlan owns scheduling recommendations and daily prioritization
- Ace consumes those systems as context and action surfaces
