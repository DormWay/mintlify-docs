# Navigation IA

DormWay's canonical navigation is a five-item model shared across LockedIn web and iOS. The goal is cross-surface consistency, not platform-by-platform reinvention.

## Canonical Main Navigation

| Order | Label | Web route | iOS tab |
|-------|-------|-----------|---------|
| 1 | Today | `/dashboard/today` | `.today` |
| 2 | Schedule | `/dashboard/schedule` | `.schedule` |
| 3 | Tasks | `/dashboard/tasks` | `.tasks` |
| 4 | Courses | `/dashboard/courses` | `.courses` |
| 5 | Library | `/dashboard/library` | `.library` |

## Placement Rules

- settings is not a main-nav item
- help center is not a main-nav item
- settings lives in the top-right access pattern on both web and iOS
- contextual sub-navigation is allowed inside a surface, but it does not change the five-item IA

## Focus Panel Contract

The inspector or focus-panel layer allows users to open details without leaving the current surface.

- current web state still uses `?inspector=`
- long-term canonical state is `?focus=`
- deep-linkable entities include tasks, assignments, courses, course lists, and events
