### `resolve`

```typescript
resolve(promptId: string, context: LLMPromptResolveContext): Promise<ServiceResult<LLMPromptRaw>>
```

Resolve a prompt with scoping cascade and optional variant.

Lookup order (most specific -> least specific):
1. prompt_id + variant + scope_type='user' + scope_id=userId
2. prompt_id + variant + scope_type='campus' + scope_id=campusId
3. prompt_id + variant + scope_type='global'
4. prompt_id + (no variant) + scope_type='user' + scope_id=userId
5. prompt_id + (no variant) + scope_type='campus' + scope_id=campusId
6. prompt_id + (no variant) + scope_type='global'

Returns the first match found.

### `update`

```typescript
update(promptId: string, input: LLMPromptUpdateInput, targetScope: LLMPromptScopeSelector): Promise<ServiceResult<LLMPromptRaw>>
```

Update an existing prompt.
In a transaction:
  1. Lock current active row
  2. Snapshot current row into llm_prompt_versions
  3. Deactivate current row
  4. Insert new active row with incremented version
  5. Persist new version snapshot
  6. Invalidate cache
