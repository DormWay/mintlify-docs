### `hasSyllabusForCourses`

```typescript
hasSyllabusForCourses(courseContextIds: string[], options: { includeTimestamps?: boolean; }): Promise<ServiceResult<{ contextIds: Set<string>; timestamps…
```

Check which courses have processed syllabi (bulk operation)
Always returns an object with contextIds Set and timestamps Map.

BREAKING CHANGE (PR #732):
- Previous: Return type was `Set<string> | { contextIds, timestamps }` (union)
- Current: Always returns `{ contextIds: Set<string>; timestamps: Map<string, string> }`
- Rationale: Simplified type eliminates runtime type checking, more predictable API
- Impact: Only one caller existed (students.routes.ts), already updated

NOTE: When includeTimestamps is true, returns fetched_at as the syllabus timestamp.
fetched_at represents when the syllabus was processed and written to service_data,
making it semantically equivalent to "processed_at" (no separate field exists).
When includeTimestamps is false, timestamps Map will be empty.

CACHING: Results are cached for 10 minutes (600 seconds) to reduce database load.
All services calling this method benefit from the shared cache.

### `findOrphaned`


Find orphaned syllabi - syllabi whose course context has no enrollments

An orphaned syllabus is one where:
1. The course context exists but has no students enrolled
2. The course was created by syllabus processing but never properly linked

This helps identify syllabi that were uploaded but the course association
was never completed (e.g., user didn't select a course, or the course
was created from syllabus extraction without enrollment)
