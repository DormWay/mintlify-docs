## Methods

### `getReadingPrepTasks`

```typescript
getReadingPrepTasks(options: GetReadingPrepTasksOptions): Promise<ServiceResult<ReadingPrepTask[]>>
```

Get reading prep tasks for upcoming classes

Queries class_sessions from syllabus data and derives prep tasks
for classes happening on targetDate (or within lookaheadDays).

Returns tasks suggesting to complete readings 1 day before the class.

### `getClassModifications`

```typescript
getClassModifications(options: GetClassModificationsOptions): Promise<ServiceResult<ClassModifications>>
```

Get class modifications for a date

Queries schedule_events from syllabus data and categorizes them into:
- Canceled classes (no_class events)
- Guest speakers
- Exams
- Special events
- Holidays/breaks
