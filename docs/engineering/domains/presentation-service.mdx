# PresentationService

PresentationService generates short, terse summaries for dashboard surfaces.

Pattern:
1. Check Redis cache for existing result
2. Check rate limit (10 calls/min/user)
3. Call LLM (Haiku) via callLLMDirect()
4. Cache result with template-specific TTL
5. On failure or AI-disabled, fall back to Handlebars template
