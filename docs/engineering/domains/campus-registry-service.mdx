# CampusRegistryService

Provides search functionality for the campus_registry reference table
which contains ~6,252 US campuses from IPEDS data.

**Source:** `services/shared/dormway-core/src/domains/campus/campus-registry.service.ts`

## Methods

### `searchTypeahead`

```typescript
searchTypeahead(query: string, limit: number): Promise<ServiceResult<CampusTypeaheadResult[]>>
```

Typeahead search for campus_registry with fuzzy matching support.
Used by onboarding to help users find their school even with typos.
Uses pg_trgm similarity for fuzzy matching (e.g., "Berkley" -> "Berkeley")
