### `shouldRunEnrichment`

```typescript
shouldRunEnrichment(campusId: string, userId: string): Promise<ServiceResult<boolean>>
```

Check if enrichment should run for this campus/user combination.

Enrichment runs if:
1. This is the first student at the campus, AND
2. Campus has no academic calendar

Returns early if:
- Not the first student (calendar should already exist)
- Calendar already exists (no enrichment needed)
