# CrewDeadlineSyncService

## Methods

### `syncDeadlines`

```typescript
syncDeadlines(crew: CrewEntity): Promise<DeadlineSyncResult>
```

Sync assignment deadlines from student_time_blocks into crew_items.
Uses source_assignment_id for dedup (INSERT new, UPDATE changed title/due_at).

Respects filters from crew.settings.modules.deadlines.filters:
- assignment_ids: sync only these specific time block UUIDs (most specific)
- assignment_types: sync only assignments matching these types (e.g. 'project', 'exam')
- No filters: sync all assignments (backwards-compatible)

Retroactive cleanup: deletes crew_items whose source_assignment_id
is no longer in the filtered assignment set.
