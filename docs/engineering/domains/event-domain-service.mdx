### `syncEventToCalendars`

```typescript
syncEventToCalendars(eventId: string): Promise<void>
```

Insert a student_time_block for every active crew member when an event
is created. Default status = 'tentative' (no RSVP yet).
Dedup via NOT EXISTS on (user_id, source='crew', sync_token).


Update a single member's time block after an RSVP change.
going → busy/active, maybe → tentative/active, not_going → soft-deleted.
