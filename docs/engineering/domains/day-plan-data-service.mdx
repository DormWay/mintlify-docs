### `getTimeBlocks`

```typescript
getTimeBlocks(userId: string, date: string, timezone: string): Promise<ServiceResult<TimeBlock[]>>
```

Get time blocks for a specific date with timezone-aware filtering
CRITICAL: Fetches ALL blocks and filters client-side to handle timezone edge cases
(e.g., Canvas ICS assignments stored at UTC midnight may fall on different dates
when converted to user's local timezone: 2025-10-31 01:00 UTC = Oct 30 21:00 EDT)

All times are stored as proper UTC and returned as ISO timestamps.
Display layer is responsible for timezone formatting.

### `getTimeBlocksInRange`

```typescript
getTimeBlocksInRange(userId: string, startDate: string, endDate: string): Promise<ServiceResult<TimeBlock[]>>
```

Get time blocks for a date range (semester-level queries)
Used by processSemester workflow to get all blocks within a term window.

Unlike getTimeBlocks() which filters for a single day, this method
queries student_time_blocks with server-side date range filtering.

### `getAssignments`

```typescript
getAssignments(userId: string, startDate: string, endDate: string): Promise<ServiceResult<Assignment[]>>
```

Get assignments/deadlines for a date range

IMPORTANT: Queries from student_time_blocks (unified source) NOT service_data.
student_time_blocks contains assignments from:
- Canvas (source='canvas')
- Syllabi/LMS (source='lms')
- Other sources

This ensures all forward-facing assignments are included in the DayPlan prompt.

### `getStudentPreferences`

```typescript
getStudentPreferences(userId: string): Promise<ServiceResult<StudentPreferences>>
```

Get student preferences including DayPlan content preferences

Fetches preferences from PreferencesService (user_preferences table) which
includes the `dayplan` category with content preferences (mode, show_suggestions,
show_wellness, show_coming_up, email_on_light_days).

Falls back to account metadata if PreferencesService is not initialized.

  forecast: { temp_max, temp_min, conditions, ... },
  threeDay: [{ date, temperature: { max, min }, conditions, ... }, ...]
