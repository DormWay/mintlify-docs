Compute ranked time suggestions for a session.

this algorithm.

### `prefillAvailabilityFromSchedule`

```typescript
prefillAvailabilityFromSchedule(sessionId: string, userId: string): Promise<{ prefilled: number; }>
```

Pre-fill a member's availability for a Find Times session from their
student_time_blocks. Only runs if the member has not already submitted
availability manually. Skips gracefully if no blocks exist.

Class/blocked times → 'avoid'
The pre-fill creates 30-min slots aligned to half-hour boundaries.
