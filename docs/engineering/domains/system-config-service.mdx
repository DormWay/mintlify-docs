# SystemConfigService

System Config Service Implementation

Provides type-safe access to runtime configuration values stored in the
system_config table. Supports in-memory and Redis caching with automatic
audit logging for all changes.

**Source:** `services/shared/dormway-core/src/domains/system-config/index.ts`


Get a config value as a string

Handles unwrapping JSON-encoded strings stored in JSONB.
PostgreSQL JSONB stores string values with their JSON quotes,
so "gpt-4o-mini" in JSON becomes the string "gpt-4o-mini" when retrieved.
This is handled automatically by the pg driver's JSONB parsing.

### `ensureDefaults`

```typescript
ensureDefaults(defaults: ConfigDefault[]): Promise<{ inserted: number; updated: number; }>
```

Ensure all default config entries exist in the database.

- Inserts missing keys with their default values.
- Updates metadata (description, constraints, default_value) on existing keys.
- NEVER overwrites the current `value` column on existing keys.

Processes entries in batches of 50 within a single transaction.
Non-fatal: logs errors but does not throw, so service startup is not blocked.
